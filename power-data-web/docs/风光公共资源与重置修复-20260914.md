# 风光公共资源与重置修复

## 根因与范围

- 光伏源图片已经位于公共目录，但加载器直接保留站点根路径；发布到嵌入壳后，原请求返回 404，正确的 `/shell/topology/shared/` 地址返回图片。
- 风电和光伏真实数据在画布中异步加载，业务清单节点为空。公共面板误用业务节点数禁用重置，且两个预览组件未提供重置端口。
- 原全屏目标只包含内部画布，公共重置按钮在其父层，因此不会随内部画布进入全屏。

## 修改

- 光伏加载器与燃气、燃煤、风电统一使用 `getTopologySharedPublicAssetUrl`。未登记图片显式报错，不再静默清空。
- 公共资源工具登记九项同字节别名，统一请求既有公共图片并复用浏览器图片缓存；对应关系由源图片散列核对，测试持续验证字节相等。
- 五种光伏专用图形继续位于公共 `public/topology/shared/assets`：太阳能板、汇流箱、逆变器、箱变、气象仪。没有新建场景独占图片目录，没有按名称替换成其他设备。
- 风光组件暴露只读就绪状态和受控重置接口；公共面板按真实就绪状态解锁重置。真正空拓扑和暂停态仍禁用。
- 重置只适配、居中现有画布，不重新请求文件、重建图元或修改筛选。正式模式全屏目标改为公共面板，重置、筛选和画布共同进入全屏。
- 恢复隐藏画布时重算尺寸；隐藏时断开尺寸观察并取消待执行的尺寸与图片刷新。

## 验证

- 修复前：光伏八种变体的发布图片地址测试全部失败；风电和光伏实际组件挂载测试均复现重置禁用。
- 修复后：81 个测试文件、496 项测试全部通过，包含两场景重置实际调用、暂停门禁、全屏祖先、两座变电站空态，以及风光十六种变体公共图片路径。
- 类型检查、发布构建、清单校验和发布产物完整性校验通过。
- 新包服务实测：光伏八种变体共 233 个图片图元、14 个唯一公共图片地址全部返回成功图片响应。
- 内置浏览器自动化仍返回“认证方式不支持”，未完成真实浏览器画面、鼠标拖动、全屏视觉验收。组件测试替换了图形引擎，不能替代像素级验收。

## 资源审计与边界

源拓扑的文件、散列、图元数、坐标及连接关系均未修改。九个散列名副本仍被八份源拓扑引用，为保持源文件可独立解析暂时保留；运行时统一为同一公共地址。删除文件数为零，释放空间为零。将来需要物理去重时，应同时迁移源拓扑引用及来源散列，不能单独删除有效引用文件。

本次没有新增第三层数据或设备业务绑定。现有风光设备四态映射尚未登记，不能把公共静态图形复用宣称为四态联动完成。
