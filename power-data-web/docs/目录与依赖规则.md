# 目录与依赖规则

## 目录职责

| 目录 | 职责 | 可以依赖 | 禁止依赖 |
| --- | --- | --- | --- |
| `app` | 应用启动、全局错误处理 | `router`、`stores`、`styles` | 具体业务模块实现 |
| `layouts` | 三类页面布局与导航装配 | `config`、`shared`、`stores` | 网页图形实例、实时连接 |
| `modules` | 路由页面及业务领域组件 | `shared`、`services`、`stores` | 跨领域页面实现 |
| `shared` | 无业务含义的组件、类型与工具 | `styles`、基础类型 | 业务模块、路由页面 |
| `services/http` | 请求取消、错误转换与传输适配 | `shared` | Vue 组件、状态仓库 |
| `services/realtime` | 单标签页实时连接与订阅去重 | `shared` | Vue 组件、网页图形 |
| `services/webgl` | 网页图形通信、生命周期与协议校验 | `shared` | 燃气、燃煤等业务命名 |
| `stores` | 可序列化的界面与领域状态 | 类型、纯工具 | 图表实例、iframe 窗口、观察器、定时器 |
| `config` | 本地只读导航与环境无关配置 | 类型、纯工具 | 组件、运行时对象 |

## 强制规则

1. 工艺页面只通过协调器请求网页图形能力，不能直接调用窗口消息接口。
2. 网页图形服务只能接收稳定业务标识和已登记的运行时配置，不能从路由参数拼接地址。
3. 图表、iframe、浏览器事件和定时器必须由适配器私有持有，并在显式释放时清理。
4. 页面级模块必须通过路由懒加载；不能在应用入口导入工艺预览资源或运行时包。
5. 普通后台模块在字段契约未确认前仅使用通用演示数据，不实现业务写入行为。
