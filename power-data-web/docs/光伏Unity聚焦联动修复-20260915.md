# 光伏 Unity 聚焦联动修复清单

## 已修复

- `SolarPower.unity` 移除旧的占位控制器，保留 `PowerPlantProcessController`。
- 新增 `SolarPowerBusinessSceneControllerAdapter`，声明能力值 `877`：初始化、节点聚焦、清除选择、设备四态、场景复位和释放。
- Unity 桥接器启动时登记光伏适配器。
- 光伏发布清单保留两个显式映射：
  - `system.solar-inverter-control` → `unit.solar-inverter.control`
  - `asset.solar-inverter` → `node.solar-inverter`

## 发布前复核

必须使用包含上述适配器和场景资产的新 Unity 构建重新生成发布包。旧发布包中的光伏场景能力值为 `97`，且没有光伏三维节点映射，不能用于验收点击联动。

## 前端验证

- 类型检查通过。
- 前端单元测试 513 项全部通过。
- 拓扑 JSON 与四态图片资源请求正常。
