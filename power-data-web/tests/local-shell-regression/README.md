# 任务-014三层本地联调夹具

该目录只验证“外层测试宿主页 → 当前嵌入壳 → Unity 模拟页”的协议链路。它使用合成九场景结构清单，**不代表**任务-039—047的正式场景、节点、动作、真实设备或资源资料。

## 启动

在三个终端分别执行：

```powershell
cd F:\WorkSpace\WebDLPro\power-data-web\tests\local-shell-regression
node server.mjs
```

```powershell
cd F:\WorkSpace\WebDLPro\power-data-web\tests\local-iframe-regression\unity-mock
python -m http.server 5511 --bind 127.0.0.1
```

```powershell
cd F:\WorkSpace\WebDLPro\power-data-web
npm run dev -- --mode local-shell-regression --host 127.0.0.1 --port 5174
```

该模式自动读取仓库内 `.env.local-shell-regression`（本地壳回归环境文件）。不要在启动前手工设置同名 `VITE_`（构建时环境变量）变量，否则会覆盖本模式所需的模拟页延迟、场景失败和离线节点失败参数。然后在浏览器访问 `http://127.0.0.1:5510`。初始化成功后可点击“查询有限状态快照”；该页会显示 `system.ack`（系统确认）、`view.changed`（视图变更）、`state.snapshot`（状态快照）和 `command.result`（命令结果）的受控摘要。

清单服务另外提供三个只读合同测试地址：`/manifest-empty.json` 保留为历史路径名，当前返回等价结构清单副本；`/missing-package/manifest.json` 返回联动包不存在404；`/missing-file/manifest.json` 返回清单文件缺失404。它们只用于验证读取器错误边界，不改变默认 `/manifest.json`，也不代表合作方真实接口。

“触发同场景流程动作”仅发送合成清单中的燃气重置动作，验证它通过 `workflow.trigger`（流程触发）进入原子事务、复用当前 Unity 场景并从燃气总览切到空的燃气明细拓扑；“触发跨场景流程动作”发送合成风电重置动作，验证切换目标场景后才执行动作并提交目标拓扑。二者均不代表正式业务映射。“发送合成节点状态”仅向本地结构清单中的 `node.gas-turbine` 发送告警四态，验证二维状态、受控 Unity 状态命令和关联结果，不能替代正式平台状态。点击 Unity 模拟页的“模拟三维对象”只会按本地清单的显式三维节点映射同步二维选择并上报受控事件，不会回发聚焦命令。“执行连续完整快照回归”使用两枚合成节点：第一份完整表同时发送两个告警，第二份较小来源修订号的非空完整表只保留燃机故障，验证缺失发电机节点恢复二维基线并向三维发送独立清除命令；正式协议仍拒绝 `items: []`，没有节点状态时平台不发送空状态批次。“执行状态边界三层回归”会先释放并重建本地会话，再依次验证同批 `node.gas-turbine` 的告警/故障以最后故障为准、燃气→风电→燃气后无需父页重推即可重投影该故障，以及模拟页拒绝离线状态时外层仍仅返回一次二维成功。最后一项由模拟页受限失败计数配合父页唯一回执验证，失败细节不会进入外层协议或生产包。“执行状态单在途重试回归”约耗时十五秒：宿主页故意不消费首个状态确认，验证五秒检查跳过在途命令、十秒截止后重新读取最新完整快照并用新消息标识发送，且新命令只返回一次二维成功结果。它只模拟父页面确认丢失，不能替代合作方真实平台状态推送。“执行基础三层回归”验证查询关联、重复消息、旧会话、伪造来源与释放。“执行超时与恢复回归”约耗时十四秒，验证连续三次取代（前两条命令均被最后一条取代）、最终失败恢复、外层十秒命令超时、**不发送后续命令时的自主补偿恢复**、迟到完成回调隔离与释放。后者通过入口查询参数只控制本地 Unity 模拟页的三个固定测试场景，不影响默认开发或生产配置。

## 当前覆盖与边界

- 覆盖合法来源、实例、会话、握手、初始原子 `view.open`（打开视图）、Unity 模拟场景切换、稳定视图变更和状态查询关联。
- 覆盖重复消息静默丢弃（不回放第二份业务回执）、连续三次事务取代、最终失败后的稳定上下文恢复、十秒命令超时、超时后无后续命令的补偿恢复和迟到 Unity 完成回调隔离；所有断言均从外层命令结果或状态快照取得，不直读子框架状态。
- 覆盖父页面五秒状态检查、同会话单在途、十秒超时后重新读取最新完整快照、新消息标识重试、显式不可恢复失败后相同状态内容不重发，以及收到真实释放结果后停止轮询和计时器。内置浏览器已实际验证正常重试成功，以及状态命令在途时释放后不产生第二次发送且回归正常取消；失败抑制也由同一控制器的自动契约测试验证，均不替代合作方平台实现。
- 覆盖连续完整快照的二维原子替换、较小 `sourceRevision`（来源修订号）仍按到达顺序生效、缺失节点二维基线恢复和三维 `clearNodeVisualState`（清除节点视觉状态）到达；这组状态回归使用夹具专用合成结构清单，不等同于平台按内部绑定生成的真实节点状态或真实燃气模型验收。
- 覆盖同批重复节点取最后一项、燃气→风电→燃气后的完整快照重投影，以及 Unity 模拟页单节点失败时外层仍只返回一次二维成功。重复项、重投影和失败计数均使用夹具固定 `nodeId` 与状态，不能替代平台真实节点状态、真实模型材质或网络异常验收。
- 该测试模式使用 600×600 的专用阈值以适配内置浏览器窗口，不能替代任务-002已经完成的 1280×720 产品最小尺寸验收。
- 外层宿主页不直连 Unity；嵌入壳不接收缺少精确启动参数的直接访问作为外层通信会话。
- 燃气夹具节点可用于验证 `topology.node.dblclick`（拓扑节点双击）；其 `nodeId` 仅是测试结构数据，不能迁移到生产配置或解释为真实设备编号。
- 外层宿主页必须给嵌入壳内嵌框架声明原生全屏权限；否则三维和拓扑的全屏请求会被浏览器权限策略拒绝，无法代表平台嵌入条件。
- 覆盖本地清单的三维反向选择到二维节点和外层事件，且确认不会回发聚焦命令。
- 任务-037浏览器回归先通过外层 `view.open` 完成“燃气实例一 → 风电 → 燃气实例二”，再由模拟页可见按钮发送旧实例、当前实例和延迟选择：旧实例不生成外层对象选择，当前实例只生成一次映射后的二维选择且不回发聚焦；释放会取消一秒延迟选择计时器，释放后不再上报对象选择。该机制只使用合成 `nodeId`，不能替代合作方节点事件验收。
- 未覆盖正式三维映射、真实 WebGL 资源、九场景业务内容、性能预算或发布验收。
