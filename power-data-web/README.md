# 电力全流程平台前端

本工程是独立于 Unity `Assets` 目录的业务前端工程，位于 `F:\WorkSpace\WebDLPro\power-data-web`，随当前 `WebDLPro` Git 仓库统一管理。Unity 场景与前端应用只会在后续通过受控网页图形通信协议集成。

## 当前已实现

- 工程初始化：开发、构建、类型检查与单元测试命令。
- 应用基础：浅色与深色设计令牌、全局错误边界、门户/后台/可视化三类布局。
- 路由与权限：五个一级模块、可视化路由、页面/数据/场景三层模拟权限。
- 通用基座：加载与降级状态、表格、表单字段、查询区、详情抽屉与图表容器。
- 基础设施边界：请求、实时订阅去重、图表适配器与网页图形协议类型。

## 开发命令

```powershell
npm install
npm run dev
npm run typecheck
npm run test:unit
npm run build
```

生产构建产物输出到 `dist`，可独立部署。使用网页历史路由时，部署服务器必须把未知路径回退到 `index.html`。

## 重要边界

1. 工艺页不直接发送窗口消息，也不根据路由参数拼接资源地址。
2. 配置中心完成前，工艺页只展示“页面配置尚未发布”，不会创建 iframe。
3. 正式鉴权、接口、实时协议、告警等级与网页图形部署信息均以 `docs/外部契约清单.md` 为准；待确认项不得被伪造为实现依据。
4. 网页图形、图表、观察器与定时器等运行时对象不得写入状态仓库。
