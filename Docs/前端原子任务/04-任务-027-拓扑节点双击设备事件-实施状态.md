# 任务-027：拓扑节点双击节点事件实施状态

> **2026-08-15 协议纠偏：** 本文按 `deviceId` 上报的实现与测试只保留为历史证据。任务-056已将双击迁移为直接上报 `sceneId + topologyId + nodeId`，不等待设备绑定；任务-027的通用双击去重机制继续复用。

**状态：** 已完成（100%）
**更新时间：** 2026-08-15

## 已实施

- `TopologyCanvas` 在复用既有命中缓存的前提下增加双击节点意图；该层只返回二维节点标识，不访问 Unity、状态仓库或跨窗口通信。
- `TopologyPanel` 仅转发双击节点意图；正式运行时从我方结构清单检查 `doubleClickBehavior: 'emit-node'`、当前场景、当前拓扑和可选 `sceneNodeId`。
- 明确声明 `emit-node` 的业务节点可直接生成节点双击意图；概念节点、未知节点和未声明上报节点均不发送，不等待平台设备绑定。
- 结构清单校验包含 `nodeId` 全局唯一、过滤视图引用闭环和静态三维映射唯一性；平台内部设备绑定不参与双击门禁。
- 单击仍即时处理，并经唯一协调器提交选择；双击不会再次写选择，也不会在本任务中下发 Unity 聚焦命令，因此不会造成双击重复聚焦。
- 正式清单到旧画布端口会回写选择快照，避免拓扑切换或全屏重渲染把运行时恢复的选择清空。
- 嵌入壳已将正式双击意图交给唯一外层通信组合根；组合根仅在握手成功、稳定上下文就绪且事件场景/拓扑与当前提交值一致时发送 `topology.node.dblclick`，并由受控发送器补齐上下文版本、关联标识、实例与会话。

## 验证

- 节点双击解析测试覆盖：已登记节点返回 `sceneId`、`topologyId`、`nodeId` 与可选 `sceneNodeId`；载荷不包含 `deviceId`，概念节点和未知节点不产生意图。
- 结构清单测试覆盖旧设备字段拒绝、`emit-node` 能力、节点唯一性和静态映射闭环；合作方设备绑定不进入前端解析。
- 组合根测试覆盖：初始化前不接纳业务命令；初始化后的节点双击必须匹配当前稳定场景/拓扑，错配意图静默拒绝。
- 2026-08-15 内置浏览器重新执行真实 Canvas（画布）双击：外层宿主页仅记录1条 `topology.node.dblclick`，节点为测试清单显式登记的 `node.gas-turbine`；浏览器双击派生的两次单击最终只向三维模拟运行时发送1次 `focusNode`。
- 当前前端全量回归：45个测试文件、268项通过；类型检查、96模块生产构建、结构清单校验和当前节点协议本地三层浏览器回归通过。

## 性能与释放

- 双击命中复用画布适配器已有节点命中缓存，不重建节点索引、路径缓存或图元资源。
- 双击处理不创建计时器，不延迟单击，不保存无界历史；外层关联标识由现有有限协议发送器生成。
- 画布、尺寸观察器和拓扑运行时继续沿既有幂等释放路径清理，本任务没有新增窗口监听器、动画帧或资源句柄。
