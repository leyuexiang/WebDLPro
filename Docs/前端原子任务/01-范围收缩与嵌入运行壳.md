# 范围收缩与嵌入运行壳任务

> **2026-08-30 视图模式补充：** 单一嵌入壳仍复用一个 Unity 实例和一个拓扑画布，但不再固定同时显示双容器。沙盘、关键环节为全屏三维；只有厂区显示三维与拓扑并存。

## 任务-001：旧职责清理清单与保护性基线

**前置：** 无。

**需求：** 逐项登记应保留、重构、删除的前端模块和依赖；记录当前用户未提交改动，禁止覆盖 Unity 资源和重叠前端修改。

**交付：** 文件级清理清单、复用映射、风险清单。

**验收：** 门户、采集、数据、系统管理、专题、导航、导览、详情、权限、请求和实时连接均有明确处理结论；任何删除动作前均能确认目标只位于 `power-data-web` 旧职责范围。

## 任务-002：单一嵌入入口与双容器壳

**前置：** 任务-001。

**需求：** 将生产入口收敛为单一可视化子应用，页面装配一个三维场景容器和一个可停用的多拓扑容器；沙盘、关键环节使用全屏三维，厂区沿用蓝色三维区与深色青色拓扑区并存样式。

**交付：** `EmbeddedVisualizationShell` 及根布局。

**验收：** 无顶部栏、侧边栏、面包屑、导览和详情；根容器填满父内嵌框架，不产生外层滚动条；三种视图模式在推荐分辨率和最小分辨率下均可用，模式切换不重建 Unity 或拓扑画布。

## 任务-003：旧页面、路由与依赖收缩

**前置：** 任务-001、002。

**需求：** 在保护用户改动的前提下删除无关页面、布局、导航、权限、请求、实时和图表模块；评估并移除不再使用的路由库和图表库依赖。

**交付：** 精简后的源码目录、依赖清单和构建配置。

**验收：** 生产构建不包含旧门户和 34 页面代码；未使用依赖被移除；类型检查、测试和构建通过；删除内容可通过 Git 恢复。

## 任务-004：稳定标识类型重构

**前置：** 任务-001。

**需求：** 将现有页面、权限、导览、详情标识改为场景、拓扑、动作、二维逻辑节点、三维节点、会话和切换事务标识；继续使用严格格式校验。平台真实设备编号不进入我方标识类型。

**交付：** 标识类型、工厂函数和运行时校验器。

**验收：** 业务 `sceneId` 只允许九个固定值，外层视图场景另允许独立 `overview`；资源文件名、中文标题、路径和空值不能进入接口；不同业务标识在类型层不能互换。

## 任务-005：场景拓扑原子清单模型

**前置：** 任务-004。

**需求：** 建立场景、视图模式、条件可选拓扑、关键环节细节、动作、节点到可选三维节点映射和统一结构清单类型，并实现跨引用和版本一致性校验。

**交付：** `SceneTopologyManifest`、加载器、校验器和错误编码。

**验收：** 九场景缺失、默认拓扑错误、动作目标错误、来源节点 `nodeId` 在联动资源内重复、节点双击能力不是 `emit-node`、三维映射引用未登记 `sceneNodeId` 或版本错配时均阻止加载；出现 `deviceId`、`deviceMappings` 或 `platformBindingCount` 旧字段也必须拒绝。

## 任务-006：部署配置与基础诊断状态

**前置：** 任务-002、005。

**需求：** 将父页面来源、Unity 子页来源、运行时入口和清单地址改为构建环境或部署清单配置；建立等待初始化、尺寸不足、配置错误、Unity 错误、拓扑错误和已释放状态。

**交付：** 部署配置读取器、基础状态组件和诊断模型。

**验收：** 正式构建不再写死本地端口；错误态包含稳定错误码和关联标识；页面异常不会显示白屏，也不会泄露完整外部载荷。
