# 任务-037：三维反向选择与外部事件实施状态

**状态：** 进行中（80%）
**更新时间：** 2026-08-05

## 已实施

- `TopologyRegistry`（拓扑注册表）新增“场景 + 三维节点”复合索引。它只从已通过发布校验的 `deviceMappings`（设备映射）构建，不按 Unity 对象名称、层级、坐标或节点前缀猜测设备。
- 新增 `UnityObjectSelectionCoordinator`（Unity 对象选择协调器）。它仅接收内层协议的稳定三维节点标识，核对当前稳定上下文与唯一活动拓扑后，精确映射设备和当前拓扑二维节点，并通过唯一可视化协调器提交来源为 `unity`（三维）的选择。
- 三维选择同步二维画布选择和相邻连线，但绝不发送 `focusNode`（聚焦节点）。二维选择来源与三维选择来源分离，阻断 Unity→二维→Unity 的回环。
- 同一内层消息标识在固定 64 条队列内只处理一次。对外的 `correlationId`（关联标识）由嵌入壳生成，内层时间戳或随机消息格式不会泄露到外层协议。
- 缺少稳定上下文、活动拓扑不一致、无效三维节点、无设备映射或映射不属于当前拓扑时，只记录固定诊断代码；不选择默认拓扑、同名节点或任何推测目标。
- `HostRuntimeComposition`（宿主运行时组合根）已将 `scene.object.selected`（三维对象选择）纳入已声明事件能力，并再次校验握手、当前场景、拓扑和上下文版本后才向父页面发送。
- 内层协议加强对象选择节点校验：只接受符合稳定标识格式且长度受限的三维节点标识，拒绝对象名称、资源路径和超长字符串。

## 验证

- 单元测试覆盖：明确映射后的二维选择和外层载荷、无映射诊断、同一内层消息重放去重、映射存在但不属于当前拓扑时的阻断，以及组合根上下文复校与事件能力发布。
- 前端完整回归：33 个测试文件、147 项测试通过；类型检查和生产构建通过。
- 内置浏览器三层本地夹具验证：点击模拟 Unity 对象后，父页面收到映射后的 `device.gas-turbine`（测试设备标识）与一个二维节点；模拟页的 `focusNode`（聚焦节点）计数保持零。夹具仅使用测试清单的明确映射，不代表正式燃气或其他八场景资料。
