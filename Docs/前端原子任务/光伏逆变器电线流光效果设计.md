# 光伏逆变器电线流光效果设计

## 目标

在 `SolarInverterProcessDetail` 预制体的六条电线（`电线` 至 `电线.005`）及控制线（`控制线`）上显示连续移动的发光脉冲，同时保留现有线路网格、材质槽和故障变色行为。

## 资源与运行关系

1. 编辑器构建器（Editor Builder）读取七条线路的原始网格，按三角形边生成顶点邻接图，并把沿网格累计的路径距离写入第二组纹理坐标（UV1，即 `TEXCOORD1`）。每条线写入不同相位，避免所有脉冲完全同步。
2. 构建器为每条线路保存一个独立的流光网格副本，并在原线路对象上配置 `ControlCircuitElectronFlowEffect` 组件。副本只供效果层使用，不替换原线路网格或材质。
3. 运行时组件在原线路可见时创建一个临时叠加渲染器，复用共享流光材质，并按原线路的启用状态同步显隐。临时对象在组件停用或销毁时释放。
4. 既有故障适配器继续只修改原线路材质的属性块。流光层与故障颜色相互独立。

## 路径距离算法

构建器把网格顶点和三角形边视为加权图，边权为顶点间距离。相同位置的顶点以零长度边连接，修复贴图接缝处重复顶点造成的路径断点。对每个连通部分执行两次最短路径搜索，取近似最长路径的一端作为流动起点，再计算所有顶点到起点的距离。二叉堆将搜索复杂度控制在 `O((V + E) log V)`，其中 `V` 是顶点数、`E` 是边数。

此距离只用于可视化脉冲，不代表电路方向或物理电流仿真。线路方向由网格局部坐标确定，调整模型方向后可重新烘焙。

## 验收

- 六条电线及控制线均引用自身源渲染器、独立路径网格和共享流光材质。
- 路径纹理坐标数量与网格顶点数一致，路径距离存在正值。
- 流光材质没有进入原线路材质槽；原网格引用不变。
- 编辑器模式测试检查以上预制体序列化关系。
