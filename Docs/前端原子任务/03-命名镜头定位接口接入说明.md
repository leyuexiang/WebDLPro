# 拓扑前端命名镜头定位接入说明

**更新时间：** 2026-09-02  
**适用前端：** `power-data-web` 拓扑可视化子应用  
**不适用：** 外层平台与 `power-scene-topology-shell` 协议

## 1. 功能边界

本功能是独立镜头动画，不属于流程步骤：

- 只将当前 Unity 业务场景相机平滑插值到已登记占位点。
- 不触发 `enterProcessStep`，不改变模型显隐、描边、选中、流程状态或设备四态。
- 前端只能传稳定 `cameraPoseId`，禁止传 Unity 坐标、旋转、层级路径或方法名。
- 第三层关键环节展示期间会拒绝第二层镜头命令，避免两个相机事务互相覆盖。

## 2. 内层命令

命令类型：

```ts
'moveCameraToPose'
```

载荷：

```ts
interface WebglMoveCameraToPosePayload {
  cameraPoseId: string
}
```

示例：

```ts
await runtime.sendCommandAndWait('moveCameraToPose', {
  cameraPoseId: 'gas-power.camera.gas-inlet',
})
```

调用前必须确认：

```ts
runtime.status.value === 'ready'
runtime.capabilities.value.includes('moveCameraToPose')
```

必须通过 `VisualizationRuntimeHostController` 调用，禁止页面自行访问 iframe、`window.postMessage` 或 Unity 方法名。

## 3. Vue 按钮接入示例

```ts
import { inject } from 'vue'
import { visualizationRuntimeHostKey } from '@/modules/visual/runtime/visualization-runtime-host'

const runtime = inject(visualizationRuntimeHostKey)

async function moveCamera(cameraPoseId: string): Promise<boolean> {
  if (!runtime || runtime.status.value !== 'ready') return false
  if (!runtime.capabilities.value.includes('moveCameraToPose')) return false

  const result = await runtime.sendCommandAndWait('moveCameraToPose', { cameraPoseId })
  return result.success
}
```

## 5. 回执与错误

`sendCommandAndWait` 只返回受控结果：

```ts
{ success: boolean }
```

常见失败：

| 错误码 | 含义 |
| --- | --- |
| `camera-pose-payload-invalid` | `cameraPoseId` 为空或格式非法 |
| `camera-pose-unknown` | 当前场景未登记该镜头点 |
| `camera-pose-configuration-invalid` | Unity 场景缺少相机控制器或镜头映射无效 |
| `process-detail-interaction-blocked` | 当前正在展示第三层关键环节 |
| `capability-unsupported` | 当前业务场景未装配命名镜头能力 |

## 6. 联调检查

1. 先进入燃气或燃煤第二层厂区并等待 Unity 状态为 `ready`。
2. 依次点击六个按钮，确认每次只播放相机插值。
3. 确认模型显隐、描边、拓扑选中和设备状态均保持不变。
4. 连续快速点击不同按钮时，后一次命令应从当前镜头位置转向新的目标点。
5. 手动操作相机时，现有相机控制器会取消未完成的自动插值并立即交还控制权。
