## 合作方契约变更复核

- 当前校验器只消费一份我方结构清单，不要求设备标识或平台绑定计数。
- 结构清单出现 `node.deviceId`、`deviceMappings`、`platformBindingCount`、绑定修订或 `emit-device` 必须阻断发布。
- 业务源节点必须声明 `doubleClickBehavior: 'emit-node'`；平台读取 `nodeId` 后在平台内部绑定真实设备，绑定结果不改写清单。

## 已交付的发布门禁

新增 `power-data-web/scripts/validate-scene-topology-manifest.mjs`（场景拓扑清单校验命令）。它通过 Vite（前端构建工具）的服务端模块加载器复用运行时同一份校验器，不会复制或漂移校验规则。命令现在只校验我方结构清单：

```powershell
cd F:\WorkSpace\WebDLPro\power-data-web
npm run validate:manifest -- --manifest <工作区内场景拓扑结构清单.json> --report <工作区内既有目录/契约报告.json>
```

命令拒绝设备字段、旧双击能力、重复 `nodeId`、重复 `sceneNodeId`、过滤视图孤立引用和结构映射不闭环。生产嵌入壳只读取一次我方结构清单。命令输出 UTF-8（统一码转换格式）JSON（JavaScript 对象表示法）报告，且只记录清单相对路径、稳定问题代码和脱敏中文摘要；不输出原始清单、绝对路径或异常堆栈。

| 结果 | 退出码 | 发布行为 |
| --- | ---: | --- |
| 清单有效 | 0 | 生成有效报告；`build:release`继续执行生产构建 |
| 清单契约无效 | 1 | 生成问题报告；`build:release`在构建前停止 |
| 参数、路径、读取、解析、报告写入或校验器加载失败 | 2 | 停止；不把未确认清单交给构建 |

命令只接受工作区内的相对路径。报告父目录必须由发布流水线预先创建；命令不会创建或覆盖工作区外文件。

## 契约覆盖范围

复用的校验器会阻断下列发布缺口：

1. 九个固定场景缺失、重复或默认拓扑跨场景。
2. 场景、拓扑、动作、设备映射和 Unity 场景映射版本不一致。
3. 多拓扑归属错误、拓扑节点或连线的孤立引用、场景动作目标错误，以及未被所属场景反向收录的孤立拓扑或动作。
4. 动作引用未登记的三维节点、路径或流程步骤。
5. 业务源节点未声明 `emit-node`，或结构清单出现 `deviceId`、`deviceMappings`、`platformBindingCount` 和绑定修订字段。
6. `nodeId` 在同一 `resourceKey` 内重复，过滤视图没有复用总图节点，或 `sceneNodeId` 反向对应多个逻辑节点。
7. 三维节点未在所属 Unity 场景映射中登记，或动作、流程、拓扑和场景版本的反向收录不闭合。
8. 平台或外部输入改写双击能力、三维节点、动作、拓扑、连线、版本或 Unity 结构映射。
