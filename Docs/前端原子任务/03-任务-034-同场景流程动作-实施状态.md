# 任务-034：同场景流程动作实施状态

## 当前状态

- 状态：进行中（70%）
- 已完成：外层 `workflow.trigger`（流程触发）能力按实际安装状态发布；受控流程处理器、同场景动作到原子 `view.open` 事务的复用、动作失败策略、稳定视图变更上报，以及动作阶段的取代与错误回归。
- 未完成：正式动作参数到 Unity 白名单字段的映射、真实 Unity 网页图形构建的流程动作回执与性能验收。

## 实现规则

1. 流程触发只接受当前原子清单已登记的 `actionId`；目标场景不是当前稳定场景时明确拒绝，留给任务-035的跨场景路径处理。
2. 同场景动作复用唯一原子切换处理器，因此不发送 `switchScene`、不释放 Unity 运行实例，也不创建第二个拓扑画布。
3. 动作成功后才激活其显式目标拓扑并递增一次上下文版本。
4. `keep-current-context`（保持当前上下文）是默认失败策略：动作失败后保持上一稳定场景与拓扑，且不激活目标拓扑。
5. 只有清单显式声明 `commit-view-with-warning`（带警告提交视图）时，动作失败才继续提交映射拓扑，并保留受控失败诊断。
6. 外层参数名称必须是当前动作允许的稳定标识；由于当前资料未提供“参数到 Unity 字段”的显式映射，任何非空参数都会被结构化拒绝，绝不静默忽略或猜测写入位置。
