# 外层内嵌框架双向通信协议

## 一、协议身份

- 通道：`power-scene-topology-shell`
- 协议版本：`2`
- 通信方式：浏览器跨窗口消息 `window.postMessage`
- 通信双方：平台父页面与 `power-data-web` 可视化子应用

外层协议与 Unity 内层 `power3d-unity` 协议职责分离，平台不得直连 Unity。

## 二、信任边界

1. 子应用只接受配置的精确父来源和当前父窗口。
2. 每条消息必须包含通道、协议版本、消息类型、`instanceId`、`sessionId` 和唯一 `messageId`。
3. 回复通过 `replyTo` 关联原消息；重复消息只返回已缓存结果，不重复执行副作用。
4. 查询参数和消息载荷不得传入任意清单地址、Unity 地址、脚本名、资源路径或模型路径。
5. 平台真实设备编号只存在于平台内部，不进入本协议。

## 三、命令

当前命令闭集从 `HOST_COMMAND_TYPES` 读取：

| 命令 | 用途 |
| --- | --- |
| `system.init` | 初始化会话与首个稳定视图 |
| `view.open` | 打开受控场景或视图 |
| `workflow.trigger` | 按公开 `actionId` 执行动作 |
| `process-detail.playback` | 控制已进入第三层的播放状态 |
| `device.states.update` | 提交完整设备状态快照 |
| `state.get` | 读取当前稳定状态 |
| `system.dispose` | 释放当前实例 |

`system.ready` 只能声明当前构建实际安装的能力。命令在未声明、上下文不匹配、版本不匹配或释放后必须拒绝。

## 四、事件

当前事件闭集从 `HOST_EVENT_TYPES` 读取：

| 事件 | 用途 |
| --- | --- |
| `system.ready` | 协议壳可接收初始化命令 |
| `system.ack` | 命令已稳定提交 |
| `command.result` | 命令完成或失败 |
| `view.changed` | 稳定视图发生变化 |
| `topology.node.dblclick` | 二维节点双击 |
| `scene.object.selected` | 三维对象反向选择到业务节点 |
| `state.snapshot` | 返回当前状态快照 |
| `system.error` | 固定、脱敏的协议错误 |

## 五、视图语义

- 第一层总览：`sceneId: 'overview'`，省略 `topologyId` 和 `processDetailId`。
- 第二层业务场景：业务 `sceneId` 与 `topologyId` 必须同时存在。
- 第三层关键环节：业务 `sceneId` 与 `processDetailId` 必须存在，省略第二层 `topologyId`；子应用内部从目录读取 `topologyDataContextId`。

`view.changed` 只报告外层业务上下文，不暴露内部拓扑文件路径、图元编号或 Unity 对象路径。

## 六、初始化与并发

1. 配置、结构清单和协议组合根就绪后发送 `system.ready`，不等待 Unity。
2. 平台可立即发送一条 `system.init`；子应用使用单槽等待 Unity 与首个稳定视图。
3. 成功 `system.ack` 和 `view.changed` 只能在真实稳定视图提交后发送。
4. 同类快速命令通过单调事务编号取代；迟到回执不得覆盖较新上下文。
5. 去重缓存、在途命令和等待槽都有固定容量与超时，释放时统一清理。

## 七、节点与状态

节点双击事件只包含 `sceneId`、`topologyId` 和 `nodeId`。三维反向选择先由当前场景映射把 `sceneNodeId` 解析为唯一 `nodeId`，再发送 `scene.object.selected`；不得把 Unity 原始对象名发给平台。

`device.states.update` 是完整快照，不是增量。每项状态只含稳定 `nodeId`、`deviceStatus`、`statusUpdatedAt` 等协议字段；状态值固定为 `normal | alarm | fault | offline`。缺失节点表示清除当前状态，不自动推断为离线。

## 八、错误与回执

- 错误必须使用固定代码和脱敏中文说明，不透传异常堆栈、文件路径或任意载荷。
- 二维状态先提交；三维同步失败按命令契约返回诊断，但不得回滚已接受的二维完整快照。
- 未知标识、能力未声明、版本冲突、超时、来源错误、容量超限和释放竞争必须有稳定错误语义。

## 九、事实源与验证

- 类型闭集：`power-data-web/src/host-bridge/host-protocol.ts`
- 组合根：`power-data-web/src/host-bridge/host-runtime-composition.ts`
- 结构清单：`power-data-web/scripts/build-gas-power-smoke-release.mjs`
- 产物门禁：`power-data-web/scripts/release-artifact-contract.mjs`

协议变化必须同步类型、运行时校验、正负向测试、发布摘要和最终产物门禁。
