## 自动视觉差异门禁

新增 `power-data-web/scripts/compare-visual-baseline.mjs` 与 `npm run test:visual`。命令只接受工作区内的两张 JPEG 截图，限制单文件不超过 25 MB、解码后不超过 1,200 万像素；它按像素尺寸兼容性、变更像素比例与平均绝对误差输出有限 JSON（JavaScript对象表示法）报告，并以非零退出码阻断阈值超限或尺寸错配。命令不写入基准、差异图或缓存，执行后只保留调用方显式提供的图片。

默认阈值为：单像素任意色彩通道差异超过 8 才计作变更像素、变更像素比例不高于 0.5%、平均绝对误差不高于 1.5。阈值必须由命令行显式传入才可调整，防止测试静默放宽。新增命令级测试覆盖同图通过、600×600与1280×720尺寸错配失败、绝对路径在读取前拒绝。

命令新增可选 `--diff`（差异图路径）参数，可在调用方预先创建的工作区目录中输出黑底亮差异 JPEG 图。输出采用“仅新建”策略，且拒绝基准图、当前图、已有文件、越界路径、缺失父目录和尺寸不一致的输入，避免差异归档覆盖用户基准或无界写入。命令级测试同时覆盖生成 JPEG 签名和覆盖基准图拒绝；本轮同图生成差异图后已删除临时输出。
