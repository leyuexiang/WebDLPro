# 测试、性能与发布任务

## 任务-089：配置与标识单元测试

**前置：** 任务-013—017。  
**需求：** 覆盖稳定标识映射、版本一致性、场景准入和孤立引用。  
**交付：** 自动化单元测试。  
**验证标准：** 非法页面、步骤、节点、路径、运行时键和跨版本资源均被拒绝；错误报告包含可定位的字段和配置版本。

## 任务-090：网页图形协议单元与联调测试

**前置：** 任务-031—042。  
**需求：** 覆盖消息过滤、握手、确认关联、超时、重试、释放和旧实例。  
**交付：** 单元测试和 iframe 联调测试。  
**验证标准：** 所有协议异常进入可诊断降级；不会形成命令回环；释放后旧回调不会影响新实例。

## 任务-091：工作台组件测试

**前置：** 任务-020—030。  
**需求：** 覆盖四档布局、导览、拓扑、详情、降级和空态。  
**交付：** 组件测试套件。  
**验证标准：** 选择步骤、节点、告警时右侧面板状态符合架构规则；小于 1280 像素时左右栏的降级交互可用。

## 任务-092：燃气端到端测试

**前置：** 任务-049—051、090。  
**需求：** 从导航进入燃气页面，分别操作导览、拓扑和 Unity 对象。  
**交付：** 燃气闭环端到端测试和运行记录。  
**验证标准：** 三处状态一致；Unity 对象选中不回发重复命令；同运行时连续切页始终只存在一个 iframe。

## 任务-093：实时订阅测试

**前置：** 任务-045—048。  
**需求：** 覆盖订阅去重、引用计数、切页丢弃旧消息、重连补偿和缓存容量。  
**交付：** 实时通道自动化测试。  
**验证标准：** 单标签页始终一条实时连接；旧页面或旧配置消息不能污染当前页面；缓存不会无限增长。

## 任务-094：性能基准与预算登记

**前置：** 任务-028、037、047、088。  
**需求：** 按目标设备档位统计拓扑节点数、边数、刷新率、首帧、内存和网页图形资源。  
**交付：** 性能基线、每页预算和压测报告。  
**验证标准：** 内网普通首屏及工艺骨架均不超过 3 秒；单网页图形实例、单拓扑实例、单实时连接约束成立；超过基线页面不得直接上线。

## 任务-095：安全响应头与发布清单校验

**前置：** 任务-015、033、088。  
**需求：** 配置精确框架来源限制、父框架限制、资源内容类型、压缩编码、缓存策略和清单校验。  
**交付：** 部署配置、发布校验脚本和回滚说明。  
**验证标准：** 来源、内容类型或压缩编码错误时不建立通信或不加载未批准资源；前端只加载清单批准的版本；回滚版本可用。

## 任务-096：可观测性与上线回归

**前置：** 任务-089—095。  
**需求：** 记录配置错误、握手失败、超时、释放失败、数据延迟和版本信息，并完成上线回归。  
**交付：** 诊断事件规范、仪表盘或日志查询、上线回归报告。  
**验证标准：** 可按关联标识定位故障；端到端、安全、性能、回滚演练全部通过；未确认的外部契约项被列为上线阻塞而非静默忽略。
