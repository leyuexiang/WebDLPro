# 光伏逆变器停机故障联动设计

## 目标

第三层关键环节使用 `逆变器关键环节9.28.fbx`。在该关键环节中执行停止命令后，将 `node.solar-inverter` 切换为故障状态，使故障效果按同一稳定节点投射到第三层模型和光伏场景设备。

## 现有边界

- 光伏业务场景节点 `node.solar-inverter` 已绑定设备四态控制。
- 第三层目录使用 `process-detail.solar-power.inverter`，其状态节点也是 `node.solar-inverter`。
- `SolarInverterFaultVisualAdapter` 负责局部设备颜色；`SolarInverterProcessDetailDynamicAdapter` 负责输出电线故障变色，并在材质支持时停止流动。
- 停止命令经 `SolarPowerBusinessSceneControllerAdapter.SetProcessDetailPlayback` 进入第三层协调器。
- 新 FBX 中存在汇流箱、多个逆变器和六条电线。场景资产仍通过 Unity 编辑器 API 生成，禁止直接改写 Unity YAML。

## 联动顺序

1. 用户在光伏逆变器关键环节执行停止。
2. 第三层协调器确认当前活动关键环节并接受停止命令。
3. 光伏适配器将 `node.solar-inverter` 更新为故障状态。
4. 光伏场景控制器将同一状态投射到场景内显式登记的逆变器设备目标；第三层协调器缓存并投射相同状态。
5. 第三层视觉绑定将选定的一个逆变器和汇流箱染红，并将显式绑定的输出电线染红；若线材质支持 `_FlowSpeed`，同时把流速置零。
6. 故障状态保持，直到平台或业务状态更新明确恢复该节点；单纯再次发送播放命令不覆盖故障状态。

## 资产绑定

- 第三层模型来源固定为 `Assets/Art/光伏场景/关键环节/逆变器关键环节/逆变器关键环节9.28.fbx`。
- 当前配置选择模型层级中的 `逆变器.001` 与 `汇流箱` 作为单点故障设备，避免把其它逆变器误染红。
- 六条 `电线` 渲染器逐条绑定；故障颜色写入支持底色属性的材质槽，支持 `_FlowSpeed` 的材质槽还会同步停止和恢复流动。
- 故障颜色使用材质属性块临时覆盖，退出或恢复状态后还原基线，不修改共享材质资产。

## 验收

- 生成的第三层预制体模型根名称为 `逆变器关键环节9.28`。
- 故障状态只将选定逆变器和汇流箱变红，其余逆变器保持基础颜色。
- 故障时六条已登记输出电线均变红；支持流动属性的线材质同时停流。恢复后还原原始颜色和流速。
- 对停止命令的集成验证应确认场景节点与第三层预制体均得到 `Fault`，且当前非活动关键环节不会被更新。

## 未覆盖边界

光伏总览中的沙盘建筑故障效果由外层完整设备状态快照聚合。第三层停止命令不会伪造或回写平台设备快照；若要求停止操作同时更新总览建筑状态，需由平台将该设备故障写入正式设备状态源，再通过 `device.states.update` 同步。
