# 页面配置与后续工艺域任务

## 一、页面配置任务通用要求

任务-052—082每一项都只创建一个页面定义，不创建新的工作台组件。每项任务均依赖任务-014、016、017、018、020—029，并必须满足以下验收标准：

1. 页面、拓扑、导览、详情、数据绑定和三维映射使用同一配置版本。
2. 路由可访问且经过权限校验。
3. 每个可点击拓扑节点均映射到详情、三维节点或明确的无三维提示之一。
4. 每个可点击导览步骤均有有效步骤标识，关联节点和路径均属于当前版本。
5. 无真实三维场景时只使用静态预览或空态，二维拓扑与导览必须可用。

## 八、任务-088：非燃气工艺域网页图形准入

**前置：** 对应页面配置任务、任务-015—017、031—042。  
**需求：** 每个非燃气工艺域启用网页图形前，提交运行时发布清单、节点映射、流程步骤、拓扑定义、资源预算、配置版本六项资料。  
**交付：** 每个域独立的准入报告。  
**验证标准：** 六项资料全部通过自动校验、资源预算和协议联调后才可切换网页图形；任一不通过则保持静态预览或空态。
