# 微电网默认拓扑六节点二维三维映射约定

## 1. 范围与交互

本次只为微电网默认的网络层+业务层+关键环节层组合登记映射，文件为 `power-data-web/public/topology/microgrid-json-preview/variants/network-business-key-process/topology.json`。其余七种拓扑变体保持原样，不增加节点或三维绑定。

二维节点选中后，前端按图元编号（`penId`）查找业务节点编号（`nodeId`）并请求统一引擎（Unity）聚焦；Unity 选择场景节点编号（`sceneNodeId`）后，前端反查业务节点并高亮对应二维图元。关系均显式登记，不根据标题、坐标、图片或数组位置推导。

## 3. 前端与 Unity 配置边界

前端为默认组合 JSON 中六个真实图元登记 `penId → nodeId → sceneNodeId`。六个设备节点均可双向选择；本次不为它们新增实时状态源或告警、故障、离线状态映射。

联合场景结构清单同步登记上述六个 `sceneNodeId`。编号定义了前端与后续 Unity 配置之间的契约，不代表离线 Unity 工程已创建目标对象或通过运行时联调。Unity 工程配置完成后，再核对六个编号并进行双向交互确认。
