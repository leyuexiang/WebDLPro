# 新版数据交换格式拓扑图复刻制作规范

**文档版本：** 2.1
**更新日期：** 2026-09-08
**适用范围：** 根据独立数据交换文件（JSON）或压缩归档（ZIP）复刻燃气、燃煤及后续工艺拓扑。

## 一、核心原则

1. 每个单层和组合层必须对应用户明确提供的一份完整拓扑文件。显示结果以该文件为唯一事实来源。
2. 筛选只执行“组合键精确查找＋完整文件切换”。禁止合并多个文件、扫描图元推断层级或修改 `pen.visible` 模拟筛选。
3. 架构层拥有独立拓扑文件，不是其他层的总和，也不是全选开关。
4. 二维组态引擎（Meta2D）、公共图片、事件监听、尺寸观察器、提示层、选择高亮和中央状态快照在所有层间复用。
5. 源文件的坐标、尺寸、旋转、文字、组合关系、连线路径、绘制顺序和画布样式必须原样保留。
6. 图元业务身份只能来自逐文件显式清单。禁止按标题、坐标、原图片地址或数组顺序在运行时推断。
7. 同一组合键或第三层关键环节只保留最新有效输入。新文件完成结构、资源、绑定和回归验证后，删除被替代的数据副本、旧散列记录及无有效引用资源；不同单层、合法组合和关键环节文件继续分别保留。
8. 所有正式拓扑节点在没有外部状态快照时默认正常。离线只消费外部明确状态；不得因首次加载、切层、缺失快照、请求失败或三维同步失败改为离线。

## 二、压缩包安全与数据提取

处理压缩包前必须只读审计：

- 统计条目数、压缩前后体积、压缩比和安全散列算法 256 位（SHA-256）。
- 拒绝绝对路径、目录穿越、空字符、大小写冲突、符号链接和异常高压缩比。
- 只读取候选数据交换文件并校验严格的统一字符编码（UTF-8）、语法、图元编号唯一性和有限几何数值。
- 包内代码、依赖清单、构建配置和脚本一律视为不可信内容，不执行、不覆盖项目文件。
- 只提取最终选定的拓扑文件及其实际引用资源；未引用资源不得导入。

若项目已有公共图标能够完整表达设备，应复用公共资源，不为每个组合复制图片。内容相同的资源按散列去重。

## 三、拓扑版本清单

每个入口维护一份版本清单。每项至少包含：

```ts
interface TopologyVariantManifestEntry {
  readonly id: string
  readonly layerIds: readonly ('architecture' | 'network' | 'business' | 'key-process')[]
  readonly combinationKey: string
  readonly topologyPath: string
  readonly sourceSha256: string
  readonly expectedPenCount: number
  readonly isDefault?: true
}
```

约束如下：

- 层级固定为架构层 `architecture`、网络层 `network`、业务层 `business`、关键环节层 `key-process`。
- 单层文件只含一个层级；组合文件含多个层级；架构层不得出现在任何组合中。
- 非架构层组合键按网络、业务、关键环节的固定顺序生成，例如 `network+key-process`。
- 组合键、文件路径和清单编号必须唯一；入口只能有一个显式默认项。
- 未登记组合不得请求文件。若已有画布，保持当前画布并显示缺少输入文件的非阻塞提示；若没有画布，显示明确空态。

推荐目录：

```text
public/topology/<拓扑编号>/
  variants/
    architecture/topology.json
    network/topology.json
    business/topology.json
    key-process/topology.json
    network-key-process/topology.json
```

## 四、筛选状态机

筛选状态只保存稳定层级编号，不保存图元编号或显隐状态。

- 勾选架构层：选中集合强制变为 `{architecture}`，同时取消其他层。
- 勾选网络、业务或关键环节任一层：先移除架构层，再加入目标层；其他非架构层保持用户选择。
- 取消任一层：只移除该层；空集合不自动恢复默认层或架构层。
- 每次更新后规范化组合键，并从版本清单精确读取唯一文件。

公共筛选组件只负责右侧单字宽竖向显示和事件转发，不解析数据、不访问画布、不实现互斥逻辑。

## 五、加载与切换事务

1. 首次创建一个二维组态引擎实例，注册一次监听器和尺寸观察器。
2. 按版本编号请求完整文件。缓存只保存未交给引擎的安全原始副本；每次打开前生成深拷贝。
3. 打开前禁用模拟数据、数据点、网络配置和初始化脚本，避免轮询、外部联网或执行输入中的行为。
4. 用逐文件资源清单替换设备图片和装饰图片地址，再应用逐文件选择策略。
5. 正式运行画布在打开前读取此刻最新的中央状态快照，并把状态直接投影到目标设备图片。
6. 清空上一文件的局部选中、高亮、连线源样式、提示、键盘游标和已应用状态缓存，重建目标文件索引。
7. 调用同一实例的完整数据打开接口。不得重建画布或重复注册监听器。
8. 切换后废弃旧视口快照，按新文件边界适应画布；公共重置按钮只恢复当前文件视图。

快速切换必须使用递增加载序号，并在可能时中止旧请求。只有最后选择对应的响应可以提交；旧请求和旧图片完成回调不得覆盖新文件。

## 六、公共资源与四态

- 设备图片使用公共正常、告警、故障、离线四态动图；状态只替换设备自身图片。
- 正式运行和独立预览均以正常作为无外部状态时的发布基线。中央状态快照存在时优先重放快照；快照未覆盖或清除覆盖时恢复正常基线，不能回退离线。
- 禁止创建状态圆点、角标、徽章、边框或遮罩作为额外状态载体。
- 区域标题背景、装饰图片、连线和普通矩形不得进入设备状态绑定。
- 若某输入文件没有设备图片，该层仍保存中央状态快照，但不得凭空创建状态图元；需要肉眼展示状态时，应补充含设备图片的输入文件。
- 同一业务节点可在一份文件中绑定多个视觉图元；每个图元只能绑定一个业务节点。
- 跨文件图元编号不一致时，为每份文件维护独立的 `penId → nodeId` 清单，切换时替换索引。

## 七、选择、提示和三维联动

- 每份文件分别登记设备图元、只读工艺矩形、区域标题背景和不可选图元。
- 只有登记设备可生成设备提示、正式业务选择、双击事件和三维联动。
- 只读工艺矩形可在二维画布显示本地选择和关联连线高亮，但不得冒充设备节点。
- 选择高亮只更新新旧集合差集，取消时精确恢复源颜色和线宽。
- 文件切换后必须重建连线索引，忽略不存在连线的历史残留引用。
- 三维反向选择只读取当前文件绑定；当前文件不存在的节点不创建设备或占位图元。

## 八、布局、重置和生命周期

- 正式拓扑使用全高画布，筛选轨固定在右侧且不挤压画布。
- 公共重置按钮位于拓扑面板公共层，通过受控画布端口调用 `resetView()`；不得为每个拓扑重复实现按钮。
- 重置不改变组合键、中央状态、业务选择，也不重新请求文件。
- 暂停时保留画布实例和中央快照，停止监听与无效绘制；恢复后重放当前组合的最新状态和选择。
- 销毁时中止请求、取消动画帧、断开观察器、解绑事件并销毁唯一画布实例，防止内存泄漏。

## 九、测试与验收

自动化测试至少覆盖：

1. 所有清单路径存在，文件散列、图元数、组合键和默认项正确。
2. 架构层独立且与其他层互斥；三个非架构层可组合；空集合不自动回退。
3. 已提供组合精确加载；未提供组合不发请求、不清空当前画布。
4. 七份文件分别校验、缓存且深拷贝隔离；重新切回不继承旧状态或高亮。
5. 公共资源存在，输入图片地址均被受控资源替换，模拟和网络配置被禁用。
6. 每个绑定图元存在于对应文件、指向正式业务节点并具备四态资源；不同文件绑定互相隔离。
7. 状态在目标数据首次打开前完成投影；加载期间到达的新状态最终生效。
8. 首次打开、切层、快照清空和状态同步失败时，所有未被外部快照覆盖的绑定设备显示正常；仅外部明确状态可显示离线。
9. 切层清除旧索引、选中和高亮；快速切换时迟到响应失效。
10. 切层不调用逐图元显隐，不合并数据，不重建二维组态引擎和公共监听器。
11. 公共重置、全屏、暂停恢复、键盘选择、提示和二维三维联动保持可用。

浏览器验收至少保存架构层、网络层、业务层、关键环节层、一个已提供组合和一个缺失组合提示的截图，并检查控制台错误、资源失败、画布尺寸和切换竞态。

## 十、禁止事项

- 禁止把架构层定义为其他层之和或全选状态。
- 禁止继续使用“物理层”替代关键环节层。
- 禁止使用区域几何交集、标题、图片地址或数组顺序推断筛选和业务绑定。
- 禁止通过 `setVisible` 或直接修改 `visible` 实现图层筛选。
- 禁止运行时拼接、取并集或裁剪多份拓扑文件。
- 禁止缓存已被二维组态引擎修改的对象。
- 禁止在输入没有设备图片时新增状态装饰物。
- 禁止执行压缩包中的代码、脚本或构建命令。
