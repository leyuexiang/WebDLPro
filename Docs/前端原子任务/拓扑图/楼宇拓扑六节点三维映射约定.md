## 2. Unity 配置

表中的 `sceneNodeId` 是 Unity 场景节点目录 `_nodes._id` 的目标值，配置时逐字使用。运行时按稳定编号匹配，不读取游戏对象（`GameObject`）名称。依照项目的控制聚合命名规则，三个控制层目标使用 `unit.<technology>-<business-role>.control` 形式；暖通、门禁和智能照明设备仍使用 `node.*` 物理节点编号。Unity 工程未在本地同步，尚未创建或验证这三个控制层目标。配置完成后再进行真实场景握手和双向交互确认。

上层三个控制系统节点只参与拓扑聚焦与反向选择，不登记设备四态图标。下层暖通、门禁、智能照明设备保留公共图标目录中的正常、告警、故障、离线四态 WebP 映射。

## 3. 前端与发布清单

前端运行时为八种独立拓扑变体逐项维护 `penId → nodeId → sceneNodeId`，选择协调器使用同一绑定表建立正向聚焦与反向高亮索引。结构发布清单的用能侧场景同步登记六个 `nodeId` 和六个 `sceneNodeId`；登记编号只定义跨端契约，不代表 Unity 对象已完成配置。
