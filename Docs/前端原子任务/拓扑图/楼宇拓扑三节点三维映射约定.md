## 2. Unity 配置要求

按[场景模型节点与拓扑节点命名规范](../场景模型节点与拓扑节点命名规范.md)，统一引擎（Unity）场景节点目录中的 `_nodes._id` 必须逐项使用上表 `sceneNodeId`；游戏对象（`GameObject`）可命名为表中的英文显示名。对象显示名仅供场景层级查看，运行时绑定按稳定编号匹配，不按中文名称、坐标或层级路径猜测。可将一个业务设备的多个模型部件绑定到同一个场景节点编号。

本约定是前端交付的编号合同，不代表当前统一引擎场景已有对应节点。统一引擎配置完成后，前端的双向选择映射即可命中这些编号。当前没有接入设备状态源，四态状态仍待单独配置。

前端生成器沿用当前全局结构清单映射版本。Unity 工程未在本地同步，本次未验证 Unity 节点是否已存在；Unity 场景离线配置应使用上述三个 `sceneNodeId`，并在场景文件同步后再确认握手版本一致。
