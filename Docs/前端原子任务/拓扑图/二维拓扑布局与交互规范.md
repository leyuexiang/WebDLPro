# 二维拓扑布局与交互规范

**适用范围：** 所有二维工艺拓扑、网络拓扑、站房拓扑、专题拓扑，以及同时承载二维拓扑与三维场景的工艺页。

**关联规范：** 图元、状态与选中规则遵循[图元与设备状态规范](图元与设备状态规范.md)；二维与三维的选择、状态和消息协同遵循[二维拓扑与三维场景联动规范](二维拓扑与三维场景联动规范.md)。本规范约束拓扑容器、节点布局、连线、交互和验收，不改变业务关系的事实来源。

## 一、拓扑关系与配置边界

1. 节点、层级、连线、协议文字和方向必须由页面拓扑配置明确提供；不得依据设备名称、页面标题、图片、坐标邻近关系或三维模型名称猜测连接关系。
2. 连线只表示配置中已声明的上游、下游或通信关系。缺少关系时保留节点和“待确认”说明，不得伪造连线。
3. 节点、路径和层级必须使用稳定业务标识关联。显示名称仅用于阅读，不能参与路由分组、缓存键或联动参数。
4. 状态更新、选中更新和缩放平移不能改变拓扑的业务关系、节点坐标或连线方向。

## 二、容器与工作台布局

1. 常规工艺页中的拓扑必须使用固定高度容器并隐藏容器外溢内容，不能因节点增多把整页向下撑高。当前基准为 `clamp(270px, 30dvh, 320px)`；窄屏可降至 `240px`，但不得取消画布内缩放。
2. 含三维场景能力的页面必须为三维区域预留稳定尺寸。三维运行时、静态预览和加载失败降级态共用同一高度预算，避免三维加载后将拓扑整体下推。
3. 层级标题所在的左侧导视区必须预留独立空白，节点、连线标签和缩放后的内容不得侵入。导视区随画布宽度自适应，当前实现范围为 `88px` 至 `124px`。
4. 拓扑容器必须提供全屏展示入口。全屏时容器接管视口内可用空间，保留明确关闭按钮和按 `Esc` 退出能力；退出后恢复原先缩放与平移状态。
5. 画布、工具栏和标题必须处于同一容器内。缩放工具栏采用悬浮方式，不参与文档流，不得改变容器尺寸或遮挡关键节点。

## 三、缩放、拖拽与可访问性

1. 拓扑必须支持鼠标滚轮缩放、工具栏放大缩小、重置视图，以及按住鼠标左键拖拽查看；触控环境应禁止浏览器默认拖拽手势干扰画布操作。
2. 默认缩放为 `100%`，当前可用范围为 `55%` 至 `225%`。缩放、平移只改变绘制视图，不得重建拓扑配置、图片缓存或实时订阅。
3. 画布必须提供明确的无障碍名称，工具栏按钮必须有中文名称、禁用态和当前缩放比例提示。
4. 视口缩小、全屏切换、容器尺寸变化后，必须重新计算节点和路径坐标；不得裁切设备名称、层级文字或缩放控件。

## 四、节点与层级布局

1. 节点坐标应在其所属层级的内容区内映射；同层节点必须保留可见间距，不能压住层级标题、相邻节点或状态点。
2. 节点卡片尺寸可随容器宽高自适应，但设备名称必须最多显示两行并在不足时省略，不得跨出卡片或叠加到其他节点。
3. 设备图元、状态点、名称和选中描边必须分层绘制。选中描边只能叠加，不得替换状态图元或改变连线事实。
4. 层级分隔线、层级名称和节点卡片的坐标规则必须共用同一左侧导视区计算方法，避免窗口缩放后节点漂移至层级名称区域。

## 五、连线路由约束

### 5.1 直连优先

1. 同层、同高度、两端之间没有第三方节点的关系必须直接水平连接；例如同一网络层中相邻的管理系统、交换机和防火墙。
2. 同列、上下相邻、两端之间没有第三方节点的关系必须直接垂直连接；例如控制器至同列现场执行设备。
3. 直接连线应从左右边中线或上下边中线出入，保持水平或垂直，不得为了统一路由规则增加无业务意义的折返线。
4. 直线会穿过第三方节点、与既有直线复用同一段、或在非端点处相交时，必须降级为避让通道，不得强行直连。

### 5.2 通道与端口避让

1. 完成全部节点布局后，统一预计算边的端口和通道；禁止每条边独立从节点中心计算折线，否则扇入、扇出关系会形成公共主干并覆盖上下游关系。
2. 同一节点同一侧的多条入边或出边必须分配不同端口，并按对端位置和稳定边标识排序；刷新、缩放后线路顺序不得随机交换。
3. 跨层或跨列关系必须使用独立通道。每条边的水平通道坐标不同，且端口引出、引入线段不得与其他边的同轴线段重合或在非端点处穿过。
4. 连线方向必须与业务方向一致，箭头以路径最后一段为准；不得因折线而让箭头固定朝右、朝下或指向错误节点。
5. 路由缓存只能在拓扑定义、容器尺寸或路由规则版本变化时重建。开发热更新改变路由规则后也必须使旧路径缓存失效，不能继续展示旧折线。

### 5.3 协议文字与视觉层级

1. 水平连线的协议文字必须浮在连线上方，并与线体至少保留 `4px` 间隔；禁止线体穿过文字、标签底色或描边。
2. 垂直连线的协议文字必须位于连线左侧或右侧；优先使用最长的空闲线段，空间不足时宁可隐藏标签，也不得压住节点、层级标题或画布边界。
3. 标签碰撞检测必须包含节点卡片、左侧导视区、画布边界和其他已占用标签区域。
4. 连线在节点之下绘制、节点在连线之上绘制；这样线路不会覆盖设备图元、名称和状态点。

## 六、性能与资源约束

1. 画布重绘必须合并到下一帧执行；连续状态变化、选择变化或尺寸观察回调不得形成无界重绘队列。
2. 设备图元应按受控地址缓存，同一地址只允许加载一次；画布设备像素比上限为 `2`，防止高分屏无限放大内存。
3. 实时状态变化只更新受影响节点的状态图元和必要描边，不重建全部节点布局、路径分组、图元缓存、缩放状态或拖拽位置。
4. 端口、通道与直连冲突检查只在拓扑或尺寸变化时执行；常规状态重绘直接复用路径缓存。路径检查必须有上界，禁止在每一帧进行无控制的全边两两扫描。
5. 页面卸载时必须取消动画帧、断开尺寸观察器、释放图元回调并清空画布适配器引用，避免切换工艺页后残留事件和内存。

## 七、验收清单

1. 常规尺寸、全屏、窗口缩小和移动端窄屏下，页面不因拓扑内容产生额外页面纵向滚动；设备、层级文字、图例和工具栏均完整可见。
2. 滚轮缩放、按钮缩放、拖拽、重置和全屏退出均可用，且退出全屏后视图状态可恢复。
3. 所有可直连的横向、纵向关系均为直线；其余关系使用清晰的独立通道。不存在公共长线复用、非端点交叉、同轴重叠或箭头指向错误。
4. 协议文字始终在连线之上或侧方，不被连线压住，也不侵入节点、层级标题或画布边界。
5. 至少覆盖容器尺寸变化、扇入扇出、直连优先、路径避让、标签避让、缩放平移、全屏退出、状态更新不改变视图，以及无控制台错误的自动化或人工回归。

## 八、禁止项

1. 禁止用增加页面高度、缩小到不可读的节点或隐藏大部分连线来规避密集拓扑问题。
2. 禁止把所有同层或同列关系强制绕成折线；无冲突的相邻关系必须直连。
3. 禁止让多条扇入、扇出边共用节点中心出口、公共主干或同一通道。
4. 禁止让协议文字置于线体下方、线上或被线体穿过。
5. 禁止依赖开发热更新后的旧路径缓存验收视觉结果；路由规则调整后必须确认已重算路径。
