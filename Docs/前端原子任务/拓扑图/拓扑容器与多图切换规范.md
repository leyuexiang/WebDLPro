# 拓扑容器与多图切换规范

## 一、容器职责

`TopologyPanel.vue` 是正式拓扑的公共容器，负责满高布局、空态、暂停态、全屏与唯一重置入口。燃气、燃煤及后续拓扑包装组件只提供数据和受控画布端口，不重复实现标题栏、状态图例、重置按钮或事件监听。

## 二、第二层布局

- 内容区只保留一行 `minmax(0, 1fr)` 画布轨道。
- 筛选轨绝对定位在画布右上角，不挤压画布。
- 筛选轨使用单字宽竖排标题和四个固定层级：架构层、网络层、业务层、关键环节层。
- 架构层独立且与其他三层互斥；空选择显示产品约定空态，不隐式恢复默认文件。

## 三、完整文件切换

每个单层和组合层必须对应一份独立数据交换格式文件。筛选过程只执行：

1. 规范化选中集合；
2. 生成稳定 `combinationKey`；
3. 从预构建索引精确查找文件；
4. 清理上一文件的数据级图元和临时交互状态；
5. 加载目标完整文件并重建文件级索引；
6. 在首次正式重绘前重放中央状态快照。

禁止合并多个文件、按标签或坐标推断层级、逐图元修改可见性或把架构层当成其他层的并集。

## 四、第三层

第三层只按稳定 `topologyDataContextId` 加载当前关键环节登记的唯一完整文件。第三层隐藏筛选轨并短路所有残留筛选事件；返回第二层时恢复进入前的组合键、文件、有效选择和最新状态。

第二层与第三层复用同一画布实例、图元注册、图片缓存、提示、选择、高亮、重置、尺寸观察器和事件监听。

## 五、重置与全屏

- 公共重置按钮只调用 `TopologyCanvasController.resetView()`，适应并居中当前完整文件。
- 重置不得重新请求数据、重建画布、改变组合键、关键环节、状态、选择或三维上下文。
- 空拓扑和暂停态禁用重置；零尺寸时只登记一次后续尺寸刷新。
- 全屏只改变容器显示状态，不创建新画布或重复监听。

## 六、性能与释放

- 组合键索引、图元索引和连线索引只在数据装载阶段构建。
- 数据缓存保持不可变，装载前创建运行时副本，避免临时样式污染缓存。
- 快速切换使用递增请求编号或中止控制器，只允许最后一次有效请求提交。
- 切换文件保留公共图片缓存和公共监听；组件卸载时再统一释放。
