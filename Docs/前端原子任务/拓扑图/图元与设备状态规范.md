# 拓扑图图元与设备状态规范

## 一、图元分类

| 类型 | 可选 | 设备提示 | 状态切图 |
| --- | --- | --- | --- |
| 背景框、区域框、标题 | 否 | 否 | 否 |
| 连线 | 否 | 否 | 否 |
| 已登记设备图片 | 是 | 是 | 是 |
| 工艺流程矩形 | 是 | 否 | 否 |

背景和连线使用完全禁用命中策略；设备和工艺矩形使用只读选择。不得用透明覆盖层阻止点击。

## 二、稳定绑定

- `penId` 只在当前数据文件内定位图元。
- `nodeId` 是跨文件的业务选择和状态主键。
- `sceneNodeId` 是 Unity 三维目标。

每份文件显式维护 `penId → nodeId → 可选 sceneNodeId`。不同文件不能假设 `penId` 相同，也不能按标题、图片地址、坐标或数组顺序补绑定。

## 三、四态图片

正常、告警、故障、离线必须由同一设备图元的四张公共图片表达。状态更新只替换 `image`，不得改变图元编号、父子关系、坐标、尺寸、文字、连线或命中区域。

资源统一位于：

```text
public/topology/shared/icons/normal/
public/topology/shared/icons/alarm/
public/topology/shared/icons/fault/
public/topology/shared/icons/offline/
```

禁止追加状态圆点、角标或状态图元，也禁止用灰度、透明度、阴影或滤镜冒充缺失状态资源。

## 四、中央状态快照

状态快照以 `nodeId` 为主键，生命周期覆盖第二层组合切换和第三层上下文切换。实时状态先写入中央快照，再只更新当前文件中已绑定的图元。

切换文件后必须读取提交时刻的最新快照，批量应用变化状态，并统一重绘一次。未出现在当前文件中的设备只更新快照，不创建设备图元。

## 五、选择与连线高亮

- 选中设备或工艺节点时显示明确轮廓，其直接关联的真实连线同步高亮。
- 关联关系只读取 `connectedLines` 和真实连线编号；装载时过滤已删除连线的残留编号。
- 每次选择只更新新旧关联集合的差集，取消选择时恢复文件加载阶段缓存的源颜色和线宽。
- 独立预览、正式二维选择和三维反向选择复用同一高亮函数。
- 高亮不得改变虚线、箭头、锚点、端点、层级或源数据。

## 六、组合图元

带 `parentId` 的子图元坐标相对父级。原始数据必须保留父子结构；确需计算辅助层世界坐标时，沿父链换算并加入循环引用和有限数保护，结果在索引阶段缓存，禁止在状态刷新或鼠标移动时重复遍历。

## 七、资源边界

拓扑版本目录只保存 `topology.json`。图片、动态图、背景和标签底图统一位于 `public/topology/shared/`，按文件哈希去重；不能因场景、组合键或第三层上下文不同而复制公共资源。
