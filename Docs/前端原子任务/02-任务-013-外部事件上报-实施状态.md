# 任务-013：外部事件上报实施状态

**状态：** 已完成（100%）
**最后更新：** 2026-08-05

## 完成结论

任务-013要求的事件发送器和载荷转换器已接入唯一生产组合根。`view.changed`（视图变更）、`topology.node.dblclick`（拓扑节点双击）、可选 `scene.object.selected`（三维对象选择）、`state.snapshot`（状态快照）、`command.result`（命令结果）和 `system.error`（系统错误）均通过统一出站校验和精确父来源发送。

本轮补齐了两个原验收缺口：父命令触发的 `view.changed` 现在携带正确 `replyTo`（回复关联标识）；普通业务事件全部改为逐字段白名单投影，错误说明按错误码生成固定脱敏文本，不再依赖调用方避免夹带 Unity 层级路径、凭据或完整不可信载荷。

真实父页面、当前子应用和 Unity 的完整三层联调属于任务-014；正式九场景设备映射属于任务-037及039—047。两者不再作为本任务发送器与载荷转换器的关闭条件。

## 本轮实现修正

1. `HostEventSender`（外层事件发送器）新增错误码到固定安全说明的常数时间映射。命令结果和系统错误只保留协议允许字段，不读取或转发上游异常文本。
2. 拓扑双击、三维对象选择和状态快照不再直接展开或复用调用方对象，全部逐字段构造新载荷；运行时错误强制转换产生的附加层级路径、令牌和原始载荷不会进入事件。
3. `sendSystemError`允许可选的原命令关联；无归属的运行时错误才允许省略 `replyTo`。
4. `HostRuntimeComposition`（外层运行时组合根）在 `system.init`、`view.open`和`workflow.trigger`成功提交后，将原命令标识传给 `view.changed`。
5. 修正三维对象选择发送器的过期注释，使其与当前生产组合根已经接线的事实一致。
6. 三层本地夹具新增初始化视图变更关联断言，并在受限日志中显示 `view.changed`关联标识。

## 性能与释放

- 错误脱敏使用固定对象查表和有限字段复制，不扫描长文本、不增加循环嵌套，也不引入缓存、监听器或计时器。
- 事件消息序列只保存一个整数；跨窗口事件经浏览器结构化克隆后不保留载荷引用。
- 组合根释放时继续依次释放握手、命令生命周期、桥接订阅和设备状态协调器，不新增资源所有者。
