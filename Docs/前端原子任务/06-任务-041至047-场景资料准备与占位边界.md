## 统一正式资料门槛

每个场景必须随同一个原子发布版本提供以下内容：

1. 可用 Unity 场景、稳定 `unitySceneKey`、资源版本、预算、加载策略、失败与降级规则，以及经过场景负责人确认的 `sceneNodeId` 清单。
2. 厂区默认拓扑和所有可切换拓扑的正式 `topologyId`、节点、连线、二维布局、图元键、状态基线与拓扑版本。
3. 显式 `nodeId → 可选 sceneNodeId` 结构映射和 `doubleClickBehavior`；所有业务源拓扑节点必须声明 `emit-node`，非业务说明和分组改用层级或标题元数据。结构清单不得写入 `deviceId`、`deviceMappings` 或绑定计数，平台读取 `nodeId` 后只在平台内部维护真实设备绑定，不修改三维节点或双击能力。
4. 外部 `actionId`、目标场景、目标视图模式、条件可选目标拓扑、可选 `processDetailId`、流程步骤、聚焦节点、路径、参数白名单与失败策略；关键环节动作禁止配置显示拓扑。
5. 每场景 0～多个关键环节的独立资源、远端展示位置、相机观察位、设备状态映射及动画/粒子/管道动态目标清单。
6. 版本一致的场景、拓扑、关键环节、动作、结构与 Unity 映射清单；我方唯一结构清单直接用于运行和全部验收，不等待平台注入设备编号或生成第二份清单。

## 模板复用与禁止事项

燃气模板可复用的仅是：原子清单结构、版本校验、单画布拓扑、图标优先布局、直线优先冲突绕行、二维/三维交互、发布门禁、三层通信、受控失败与回归方式。不得复制 0813 燃气基线的 23 个节点、22 条连线、三个聚焦映射、四个受控动作、具体坐标、设备状态或任何模型对象关系。

在正式资料到位前，七个场景应继续保持 `scene-content-unavailable`。这是防止场景切换误提交的保护性行为，不能作为任务-041至047的业务验收。
