# 任务-014：三层本地联调环境实施状态

**状态：** 已完成（100%）  
**最后更新：** 2026-08-04

## 已完成的保护性基础

1. 新增 `power-data-web/tests/local-shell-regression`，提供测试专用“外层宿主页 → 当前嵌入壳 → Unity 模拟页”链路；现有两层 `local-iframe-regression` 保持不变。
2. 测试宿主先注册监听器，再加载嵌入壳；它只通过 `power-scene-topology-shell`（外层协议通道）发送 `system.init`（系统初始化）、`state.get`（状态查询）和 `system.dispose`（系统释放），不直连 Unity。
3. 测试服务动态提供合成九场景清单，仅燃气场景带一枚设备双击节点；清单不含正式资源路径、业务动作或生产设备资料。
4. 内置浏览器已验证三层 iframe 层级实际建立，并发现并修复部署配置中把外层宿主页来源错误复用于 Unity 直接父页面来源的问题：现使用独立 `VITE_POWER_UNITY_PARENT_ORIGIN`（Unity 直接父页面来源）并保持精确来源校验。
5. 浏览器实测已通过：`system.ready → system.init → system.ack`（系统就绪、初始化、确认）、初始原子 `view.open`（打开视图）、Unity 模拟场景最终完成事件、`view.changed`（视图变更）、`state.get → state.snapshot`（状态查询与快照关联）和燃气测试节点的 `topology.node.dblclick`（拓扑节点双击设备上报）。
6. 修复 `system.dispose`（系统释放）过早确认问题：外层 `command.result: disposed`（命令结果：已释放）现在等待 Unity 宿主清理 iframe、连接器、观察器及待确认表后发送；浏览器实测回包后内层 iframe 数量为零，并显示“运行时已释放”。
7. 测试宿主页新增“执行基础三层回归”：自动验证状态快照与命令结果的原请求关联、重复 `state.get`（状态查询）仅产生一次快照而为每个原请求回放关联结果、旧会话静默拒绝、同源但非当前父窗口的伪造来源静默拒绝和释放确认；内置浏览器实测该回归通过且释放后内层 iframe 数量为零。
8. 测试宿主页新增“执行超时与恢复回归”：风电短延迟验证新燃气事务立即取代旧事务；配电最终失败回执验证上一稳定燃气上下文恢复；光伏延迟超过十秒验证外层 `command.timeout`（命令超时）及迟到最终完成回调无法覆盖恢复事务；内置浏览器实测全部通过且最终释放后内层 iframe 数量为零。

## 任务关闭结论

任务-014只交付三层本地联调环境及其回归夹具。两类浏览器自动回归已覆盖其正常、重复、来源隔离、快速取代、失败、超时、迟到回调和释放关闭条件，故本任务关闭。
