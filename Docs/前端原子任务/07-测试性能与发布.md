# 测试、性能与发布任务

## 任务-048：外层与内层协议单元测试

**前置：** 任务-007—013、018—019。

**需求：** 覆盖两层信封、逐类型载荷、来源、窗口、实例、会话、能力、确认、去重、超时、容量和释放。

**交付：** 协议测试套件。

**验收：** 两个通道完全隔离；错误来源和旧会话不能进入协调器；响应均按原请求关联；未知类型和超大载荷被拒绝。

## 任务-049：清单与动作映射契约测试

**前置：** 任务-004、005、023、039—047。

**需求：** 自动校验九场景、默认拓扑、多拓扑、动作、设备、流程、路径和版本的完整性。

**交付：** 发布前契约校验命令和报告。

**验收：** 任一孤立引用、版本错配、双击设备缺少 `deviceId` 或三维映射缺少 `sceneNodeId` 都使构建失败。

## 任务-050：双容器与多拓扑组件测试

**前置：** 任务-002、023—030。

**需求：** 覆盖上下布局、尺寸不足、全屏、缩放、平移、多图切换、单击、双击、状态增量和释放。

**交付：** 组件测试和视觉回归截图。

**验收：** 选择变化不重建拓扑；双击只额外上报一次设备事件；切换后视图状态按策略恢复；不存在外层滚动条和资源回调累积。

## 任务-051：Unity 多场景编辑器与构建测试

**前置：** 任务-015—022。

**需求：** 覆盖九场景登记、加载、卸载、旧事务过滤、流程动作、聚焦、状态、路径、复位、失败恢复和释放。

**交付：** Unity 编辑器测试、WebGL 构建测试和资源报告。

**验收：** 同一时刻只有一个活动业务场景和一个桥接实例；切换后控制器绑定正确；正式包不默认启用开发构建。

## 任务-052：三层通信端到端测试

**前置：** 任务-014、031—038。

**需求：** 在真实浏览器中验证“外部宿主页 → 当前可视化子应用 → Unity 模拟或真实包”的完整通信链。

**交付：** 自动端到端用例、日志和失败截图。

**验收：** 初始化、同场景动作、跨场景动作、拓扑双击、三维选择、设备状态、快速切换、错误来源和释放全部可重复通过。

## 任务-053：九场景逐项验收

**前置：** 任务-039—052。

**需求：** 对九个场景分别执行初始进入、全部拓扑、全部动作、设备映射、状态、失败和释放验收。

**交付：** 九份独立验收记录和一份总矩阵。

**验收：** 任一场景缺少拓扑、动作、设备、资源预算或版本资料时不得计为完成；燃气通过不代表其余场景自动通过。

## 任务-054：长时间运行与性能预算

**前置：** 任务-050—053。

**需求：** 在目标浏览器和硬件下测试首屏、场景下载、场景首帧、拓扑首帧、连续切换、消息吞吐、内存、显存和帧率。

**交付：** 每场景资源预算、性能报告和优化记录。

**验收：** 九场景不全部进入首屏数据文件；连续轮换场景和拓扑后资源不持续单调增长；消息、缓存和重绘不形成无界队列。

## 任务-055：安全部署、版本发布与接入说明

**前置：** 任务-048—054。

**需求：** 形成子应用、Unity、场景资源和清单的原子发布目录；配置 HTTPS、来源白名单、内容安全策略、资源类型、压缩、缓存和回滚；编写父页面接入说明。

**交付：** 发布脚本、部署清单、回滚方案、父页面接入示例和上线检查表。

**验收：** 父页面来源、子应用来源和 Unity 来源精确匹配；旧版本可一键回滚；入口短缓存、版本资源长期缓存；父页面按协议完成监听早于加载、会话更新和资源释放。
