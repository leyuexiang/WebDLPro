1. 燃气场景的视觉、拓扑布局连线和二维/三维交互，统一以 `Builds/Releases/燃气发电场景与拓扑图联动包0813` 为验收基线。回归必须覆盖 23/22 总览、16/13 燃气轮机、13/6 余热锅炉、15/10 蒸汽轮机，以及单实例、原生全屏、聚焦描边、空白清除和总览复位。
2. 后续节点协议与状态包必须继承上述基线，不得因升级 Unity 结构版本、清单或部署方式而回退布局、路由或交互。0813 包中23个源节点全为 `none` 是历史缺口，下一节点协议包必须改为 `emit-node`。
3. 构建器必须显式区分本地测试包、合作方联调包和正式包；只有本地测试包可通过开关生成流程按钮、状态面板和自测页，后两类只允许干净根入口。三类包都必须复用一个 Unity 实例和一个拓扑画布，完整规则见[测试包与正式包输出标准](测试包与正式包输出标准.md)。
4. 合作方联调包和正式包采用平台服务与可视化服务独立部署。本机 `127.0.0.1` 地址只能作为本地测试证据；交付验收必须使用精确平台父来源、可视化壳来源、Unity入口和结构清单地址，平台不修改我方压缩构建产物。
5. 只有新的自动化、内置浏览器或真实平台证据满足对应任务关闭条件时，才提高进度；只同步文档口径不调整百分比。

### Unity 网页图形缓存与内存防错基线

1. `webGLDataCaching`（网页图形离线数据缓存）必须保持 `0`。Unity 构建入口也必须在 `BuildPipeline.BuildPlayer`（播放器构建管线）之前显式关闭 `PlayerSettings.WebGL.dataCaching`，并在结束时恢复编辑器会话原值；不得依赖操作者手工勾选。
2. 离线数据缓存关闭后，浏览器不得把 Unity 主播放器资源长期写入站点持久化缓存。它不影响带版本号发布目录中脚本、样式、清单和场景资源包的 HTTP（超文本传输协议）缓存策略；两类缓存不得混为一谈。
3. 关闭新包离线缓存不会删除旧包已写入的浏览器站点数据。出现旧包占用、版本切换异常或网页程序集内存不足时，测试人员必须清理该站点数据并关闭旧测试页或旧 Unity 实例，再进行复验。
4. 网页程序集启动内存、自动增长和最大内存是独立设置，不能通过开启离线数据缓存解决内存不足。当前燃气基线为初始 `256MB`、几何自动增长、单次增长封顶 `64MB`、最大 `768MB`；任何调整必须重新构建并验证启动、握手、燃气资源包加载和连续切换。
