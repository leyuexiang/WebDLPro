# 任务-025：拓扑面板配置化与容器布局实施记录

**状态：** 已完成。
**最后更新：** 2026-08-05。

## 结论

拓扑面板已去除燃气标题、固定连线图例和固定离线状态文案。标题、图例和设备状态摘要均由当前拓扑配置生成；同一组件可在任意已发布拓扑中复用。

## 调整内容

- 拓扑配置新增必填 `title`，空拓扑也保留已发布页面标题。
- 面板只显示当前连线实际声明的证据图例。
- 面板按当前节点四态配置计算状态摘要，不再把燃气离线提示套用到其他场景。
- 面板网格固定为“标题、状态、可收缩画布”三行；常规态和全屏态均裁剪外溢，控件位于画布内部。
- 全屏、Esc退出、缩放、平移和深色工业视觉保持不变。

## 本轮正式清单接入

- 嵌入壳读取远端清单后，再次通过 `TopologyRegistry` 的跨引用校验；任一阶段失败均保持诊断态，不创建半份索引或画布运行时。
- 正式清单通过 `ManifestTopologyRuntimePanel` 接入唯一 `TopologyCanvas`。等待外层 `system.init` 时只显示无业务含义的等待态，不把燃气基线或清单首项误判为当前场景。
- `ManifestTopologyCanvasPort` 将正式拓扑投影到既有画布，并同步拓扑、选择与视图状态；切换期间不创建隐藏画布、临时图元或第二个图元缓存。
- 旧燃气配置仅继续提供当前 Unity 单实例的启动登记，已不再决定二维拓扑标题、节点、连线或选择。

本任务仍不伪造九场景拓扑，也不根据场景名、模型名或资源名推断配置。外层初始化现已与 `view.open` 事务组合：只有合法握手、唯一画布、Unity 运行时和正式清单均就绪后才可激活目标拓扑；未提供正式九场景内容和真实浏览器联调前，不能宣称九场景拓扑已完成验收。

## 验证

展示模型单元测试使用风电与微电网夹具，确认标题、四类连线图例和四态状态均来自当前拓扑配置，不依赖燃气文字；空拓扑与空白标题测试确认不猜测结构或业务名称。正式清单投影、单画布端口、运行时准备/激活、视图快照及外层组合根均有定向回归。

2026-08-05 全量前端单元测试通过：31 个测试文件、132 项测试；`npm run build` 的类型检查和生产构建通过。

内部浏览器验证覆盖 600×600 最小容器与 1280×720 常规尺寸：

1. 600×600 下嵌入壳的客户端尺寸与滚动尺寸均为 600×600，没有外层滚动；拓扑面板为 600×275，画布为 568×101，缩放工具栏底部为 569，仍在可视区域内。
2. 1280×720 下进入、退出拓扑全屏均可用；退出按钮、Esc 提示和唯一画布均可见，嵌入壳滚动尺寸与客户端尺寸一致，控制台无错误。
3. 本地夹具的左侧测试控制栏会覆盖 600 宽度下因媒体规则移动到左侧的全屏按钮；该栏不属于生产嵌入壳。最小尺寸仍验证了面板、画布和缩放控件没有被自身布局裁剪，全屏实际交互已在 1280×720 完成验证。
