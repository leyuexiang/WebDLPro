# 任务-002：单一嵌入入口与双容器壳实施记录

> **历史证据边界（2026-08-30）：** 本文双容器结果是当时实现证据。当前壳切换三种模式：沙盘全屏三维、厂区三维与拓扑并存、关键环节全屏三维；模式切换复用原 Unity 实例和拓扑画布。

**状态：** 已完成代码、类型、单元测试、生产构建和内部浏览器响应式验证；真实 Unity 网页图形构建仍由后续多场景任务验收。

## 一、变更结果

1. 新增 `power-data-web/src/app/EmbeddedVisualizationShell.vue`。
   - 根容器固定占满父内嵌框架可用视口。
   - 仅包含上方 Unity 三维容器和下方二维拓扑容器。
   - 根壳没有顶栏、侧栏、面包屑、工艺导航、导览或设备详情。
   - 复用现有燃气蓝色三维视口和深青色拓扑视觉；本地选择只更新二维高亮，不绕过后续协调器直接调用 Unity。
2. 修改 `power-data-web/src/router/index.ts`。
   - 根路径默认跳转至 `/embed`。
   - `/embed` 懒加载嵌入壳；旧路由暂时保留，等待任务-003按清理清单移除。
3. 修改 `power-data-web/src/app/AppErrorBoundary.vue`。
   - 移除“返回门户”入口，避免嵌入壳故障态反向暴露已退出职责。

## 二、范围与复用边界

- 现阶段只使用已验证的燃气总览作为视觉和运行时基线。
- 没有实现外层双向通信、九场景切换、多拓扑、设备双击上报、正式部署配置或诊断模型；这些功能分别留给后续原子任务。
- 不删除门户、后台、专题、三栏工作台或旧依赖，避免与用户未提交改动冲突；清理动作留给任务-003。
- 不修改 Unity 场景、脚本、资源、构建设置或现有本机运行时登记。
