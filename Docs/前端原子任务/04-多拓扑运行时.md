# 多拓扑运行时任务

> **2026-08-15 协议纠偏：** 本组只消费我方结构清单。平台不注入设备编号或绑定映射；`nodeId` 在同一 `resourceKey` 内全局唯一，双击、状态和三维反查均按节点编号处理。任务-056已完成旧设备映射路径迁移。

## 任务-023：多拓扑类型与注册表

**前置：** 任务-004、005。

**需求：** 将单 `topologyKey` 配置改为场景下的默认拓扑和可切换拓扑清单；每个系统维护一套总拓扑，子层级以 `sourceTopologyId`、`visibleNodeIds` 和 `visibleEdgeIds` 显式过滤总图；结构清单固定 `nodeId`、可选 `sceneNodeId` 和节点双击行为；运行时直接消费结构清单，不接受平台设备注入。

**交付：** 拓扑类型、注册表、加载器和校验器。

**验收：** 一个场景可登记总拓扑及多个子层级过滤视图；子层级完整保留当前主题从顶层到底层的显式链路，无关节点和连线隐藏，且不复制节点或连线事实；拓扑不能跨场景误用；结构清单出现 `deviceId`、`deviceMappings` 或 `platformBindingCount` 时发布失败；`doubleClickBehavior` 由结构清单声明且平台不可修改；业务节点使用 `emit-node`，静态 `nodeId → sceneNodeId` 映射和资源内节点唯一性校验通过。

## 任务-024：单画布多拓扑运行时

**前置：** 任务-023、现有画布适配器。

**需求：** 建立拓扑准备、激活、总拓扑过滤、视图状态保存、有限缓存和销毁接口；始终复用一个活动画布实例。子层级从总拓扑索引生成，不嵌套扫描全部节点与连线。

**交付：** `TopologyRuntime`。

**验收：** 切换总拓扑与子层级不创建隐藏画布或复制业务对象；隐藏节点不绘制、不命中，重新显示时从最新权威状态恢复；最近拓扑解析缓存和视图状态缓存有容量上限；卸载后取消动画帧、观察器和图元回调。

## 任务-025：拓扑面板配置化与容器布局

**前置：** 任务-002、023、024。

**需求：** 移除燃气标题硬编码，按当前拓扑配置显示标题、图例和状态；配置化复用 0813 基线已确认的深色工业风、分层色带、图标优先节点、状态图元、直线优先连线、协议标签、原生全屏和缩放规则。普通节点不得恢复独立卡片底板；常驻文字只保留图标边框下方一行小字，完整名称通过悬浮、键盘聚焦、选中或触屏单击提示。具体制作基线以[拓扑容器与多图切换规范](拓扑图/拓扑容器与多图切换规范.md)为准。

**交付：** 精简后的拓扑面板。

**验收：** 九场景和任意拓扑均不需要复制组件；图元完全铺满图标盒，约0.5像素层级描边贴边覆盖在内侧，约6.4—7.2像素单行小字位于图标盒外，完整名称在鼠标、键盘和触屏路径均可读取；运行时只使用拟物化 Cisco 风受控资源，离线徽标透明底灰色虚线环在深浅背景下语义一致；空白单击清除节点及关联路径选择，拖拽结束不误清除；常规态与 Unity 实际视口同宽，全屏态与三维一致使用浏览器原生全屏并由唯一画布填充剩余高度，平台每层内嵌框架均授予全屏权限；合法最小外层尺寸下无外层滚动和控件遮挡，层级文字与辅助小字按响应式比例缩小，提示锚点保持在画布安全区。

## 任务-026：拓扑更新性能修复

**前置：** 任务-024。

**需求：** 拆分拓扑定义、选择、设备状态和容器尺寸监听；只有拓扑或尺寸变化时重建节点索引与路径缓存。

**交付：** 优化后的 `TopologyCanvas` 和画布适配器测试。

**验收：** 单次选择变化只调用 `setSelection`；单设备状态变化不调用 `setTopology`；连续更新合并到动画帧且无嵌套全边扫描。

## 任务-027：拓扑节点双击节点事件

**前置：** 任务-023—026。

**需求：** 新增画布双击命中和节点事件；单击立即选中，双击额外生成对外节点事件，不固定延迟单击，也不等待平台设备绑定。

**交付：** `dblclick` 处理、幂等选择和事件载荷。

**验收：** 双击节点准确返回 `sceneId + topologyId + nodeId`；不等待平台设备标识；`none` 节点不发送；双击产生的重复单击不重复下发相同三维聚焦命令。

## 任务-028：拓扑单击与三维聚焦

**前置：** 任务-021、023、024。

**需求：** 单击节点时立即更新二维描边和路径，有 `sceneNodeId` 且 Unity 能力就绪时发送 `focusNode`；来源为 Unity 时阻断回写。

**交付：** 拓扑选择协调接口和来源标识。

**验收：** 三维失败不撤销二维选择；同一关联标识只执行一次；无三维映射节点不猜测模型。

## 任务-029：节点状态全量快照与多图状态缓存

**前置：** 任务-023、024、026。

**需求：** 接收按 `nodeId` 编号的四态完整快照，保存当前 `resourceKey` 最新一份最多500项的权威状态表；直接投影到二维节点，再从结构节点派生可选三维目标。每批按到达顺序原子替换，非活动拓扑只保存有限派生缓存，缓存淘汰后必须能从权威快照重建。

**交付：** 全量状态适配器、运行时节点索引和批量更新接口。

**验收：** 上一批存在而本批缺失的节点清除动态覆盖并恢复发布基线；未识别节点忽略；非法四态在协议入口拒绝；同一批重复节点由最后一项覆盖；状态变化不改变选择、缩放和平移；结构清单不得包含真实设备编号或绑定映射。

## 任务-030：图元资源迁移与拓扑释放验收

**前置：** 任务-024—029。

**需求：** 将正式运行图元从 `Docs` 迁入前端资产或独立资源包，保留现有资源规范；补齐切换、全屏、释放和缓存回归。

**交付：** 正式图元登记表、资源迁移说明和组件测试。

**验收：** 生产源码不依赖文档目录；图元按受控键和四态解析；多次切换后图片缓存、回调和画布缓冲区不持续增长。
