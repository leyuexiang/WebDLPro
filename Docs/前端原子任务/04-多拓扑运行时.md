# 多拓扑运行时任务

## 任务-023：多拓扑类型与注册表

**前置：** 任务-004、005。

**需求：** 将单 `topologyKey` 配置改为场景下的默认拓扑和可切换拓扑清单；补充 `nodeId`、`deviceId`、`sceneNodeId` 和双击行为。

**交付：** 拓扑类型、注册表、加载器和校验器。

**验收：** 一个场景可登记多套拓扑；拓扑不能跨场景误用；可双击设备节点缺少 `deviceId` 时发布失败。

## 任务-024：单画布多拓扑运行时

**前置：** 任务-023、现有画布适配器。

**需求：** 建立拓扑准备、激活、视图状态保存、有限缓存和销毁接口；始终复用一个活动画布实例。

**交付：** `TopologyRuntime`。

**验收：** 切换拓扑不创建隐藏画布；最近拓扑解析缓存和视图状态缓存有容量上限；卸载后取消动画帧、观察器和图元回调。

## 任务-025：拓扑面板配置化与容器布局

**前置：** 任务-002、023、024。

**需求：** 移除燃气标题硬编码，按当前拓扑配置显示标题、图例和状态；保持并配置化复用已确认的深色工业风、分层色带、节点卡片、状态图元、连线证据、协议标签、全屏、缩放和文字避让规则。具体制作基线以[拓扑容器与多图切换规范](拓扑图/拓扑容器与多图切换规范.md)为准。

**交付：** 精简后的拓扑面板。

**验收：** 九场景和任意拓扑均不需要复制组件；常规态与 Unity 实际视口同宽，全屏态按子应用视口自适应覆盖且画布填充剩余高度；最小容器尺寸下无外层滚动、控件遮挡、层级文字或节点名称裁切。

## 任务-026：拓扑更新性能修复

**前置：** 任务-024。

**需求：** 拆分拓扑定义、选择、设备状态和容器尺寸监听；只有拓扑或尺寸变化时重建节点索引与路径缓存。

**交付：** 优化后的 `TopologyCanvas` 和画布适配器测试。

**验收：** 单次选择变化只调用 `setSelection`；单设备状态变化不调用 `setTopology`；连续更新合并到动画帧且无嵌套全边扫描。

## 任务-027：拓扑节点双击设备事件

**前置：** 任务-023—026。

**需求：** 新增画布双击命中和设备事件；单击立即选中，双击额外生成对外设备事件，不固定延迟单击。

**交付：** `dblclick` 处理、幂等选择和事件载荷。

**验收：** 双击设备节点准确返回 `nodeId + deviceId + 可选 sceneNodeId`；非设备节点不发送；双击产生的重复单击不重复下发相同三维聚焦命令。

## 任务-028：拓扑单击与三维聚焦

**前置：** 任务-021、023、024。

**需求：** 单击节点时立即更新二维描边和路径，有 `sceneNodeId` 且 Unity 能力就绪时发送 `focusNode`；来源为 Unity 时阻断回写。

**交付：** 拓扑选择协调接口和来源标识。

**验收：** 三维失败不撤销二维选择；同一关联标识只执行一次；无三维映射节点不猜测模型。

## 任务-029：设备状态增量与多图状态缓存

**前置：** 任务-023、024、026。

**需求：** 按 `deviceId` 合并四态更新，映射到当前拓扑节点和当前三维节点；非活动拓扑只保存有限状态快照。

**交付：** 状态适配器、时间戳校验和批量更新接口。

**验收：** 过期更新被丢弃；缺失或非法状态归一为离线；同一帧同一设备只保留最新值；状态变化不改变选择、缩放和平移。

## 任务-030：图元资源迁移与拓扑释放验收

**前置：** 任务-024—029。

**需求：** 将正式运行图元从 `Docs` 迁入前端资产或独立资源包，保留现有资源规范；补齐切换、全屏、释放和缓存回归。

**交付：** 正式图元登记表、资源迁移说明和组件测试。

**验收：** 生产源码不依赖文档目录；图元按受控键和四态解析；多次切换后图片缓存、回调和画布缓冲区不持续增长。
