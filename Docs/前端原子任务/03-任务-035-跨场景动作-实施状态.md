# 任务-035：跨场景动作实施状态

## 当前状态

- 状态：进行中（70%）
- 已完成：跨场景流程动作范围识别、目标场景与拓扑的原子清单校验、原子切换事务复用、目标场景就绪后动作执行、目标拓扑最终激活、稳定视图上报，以及取代和物理回退复用。
- 未完成：真实 Unity 网页图形构建的分阶段加载反馈、正式动作参数映射、正式九场景动作与资源释放验收。

## 实现规则

1. 流程触发路由器只比较“清单动作目标场景”与“当前稳定场景”；相等进入任务-034同场景路径，不等才进入本任务路径。
2. 跨场景处理器把动作投影为唯一 `view.open`（原子打开视图）事务，严格执行“预解析目标拓扑 → 切换三维场景 → 等待目标场景确认 → 执行动作 → 激活拓扑 → 提交稳定上下文”。
3. 协调器快照在事务中同时保存上一个稳定上下文、目标场景、目标拓扑、Unity 子系统状态与拓扑子系统状态；因此旧场景、目标场景和拓扑准备阶段可由受控状态快照诊断，尚未提交的目标不会作为稳定视图对外发布。
4. 目标动作未完成前不激活目标拓扑。旧事务、迟到进度和迟到命令结果先由事务标识过滤，跨场景失败继续复用任务-036的物理回退或明确错误态。
