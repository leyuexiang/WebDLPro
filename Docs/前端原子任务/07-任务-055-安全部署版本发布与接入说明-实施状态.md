## 2026-08-08 当前协议兼容性复核

本轮新建且保留了失败证据包 `Builds/Releases/gas-power-smoke-task055-reverify-5531-20260808-1600`，使用旧 Unity 基线 `task051-final-20260805-2220`。其清单契约为 0 项问题，类型检查与 95 个模块生产构建通过；入口、清单、前端版本资源、Unity 网页程序集及 POST（提交请求）拒绝响应的缓存、媒体类型与安全响应头也全部符合本地基线。

但应用内浏览器实际初始化在切换燃气场景阶段失败，外层返回 `scene.switch.failed`（场景切换失败），内层报 `topology.invalid`（拓扑配置无效）。对已复制 Unity 压缩产物进行只读解压核对后确认：`unity.data.br`、`unity.framework.js.br` 与 `unity.wasm.br` 都不包含 `sceneActivationId`（物理场景激活标识）；而当前前端已将该字段设为 `sceneChanged`（场景切换完成）回执的必填项，用于隔离同名场景往返后的迟到事件。因此这不是安全响应头阻断，也不是清单错误，而是旧网页图形构建与当前协议不兼容。

已在 Unity 正式构建入口增加版本化协议元数据生成：只有播放器成功构建后，才会在同一 Unity 输出目录写入 `webgl-protocol-capabilities.json`。`power-data-web/scripts/build-gas-power-smoke-release.mjs`（燃气最小联调包构建脚本）在写清单、创建暂存目录、构建前端和复制 Unity 资源之前读取并校验该小型文件，不再通过解压和搜索大型二进制字符串猜测运行时能力。以旧基线执行验证时命令受控失败，最终目录、暂存目录与清单产物均未创建。失败证据包不删除、不覆盖，供后续 Unity 重构建后的对照回归使用。
