# Unity 多场景运行时任务

> **2026-08-31 第三层补充：** 新第三层关键环节使用 `prepareProcessDetail → commitProcessDetail` 两阶段事务和 `processDetailId` 加载、展示细节资源；准备或前端布局提交失败时使用 `abortProcessDetail` 取消候选资源。同场景关键环节直接切换复用该事务，不先退出第二层。`enterProcessDetail` 与 `enterProcessStep` 仅作历史兼容，不得再驱动新链路。

## 任务-015：常驻启动场景与构建设置

**前置：** 任务-004、005。

**需求：** 新建轻量 `Bootstrap` 启动场景，登记九个业务场景；把桥接、场景协调、加载反馈和公共服务放入启动场景。

**交付：** 场景文件、构建设置和场景目录。

**验收：** 构建入口不再只包含 `SampleScene`；启动场景不承载任何单一业务场景重资源；九个业务场景均有唯一 `sceneId → unitySceneKey` 映射。

## 任务-016：统一业务场景控制接口

**前置：** 任务-015。

**需求：** 定义每个业务场景必须实现的初始化、关键环节细节进入/退出、历史流程兼容、节点聚焦、状态更新、路径流动、复位和释放接口。

**交付：** `IBusinessSceneController`、场景能力登记表和基类或适配器。

**验收：** 桥接管理器不再直接依赖燃气 `PowerPlantProcessController`；不支持的能力通过清单显式缺失，不允许静默空执行。

## 任务-017：多场景异步加载协调器

**前置：** 任务-015、016。

**需求：** 实现目标校验、旧场景卸载、目标资源加载、场景初始化、失败恢复和事务标识过滤。

**交付：** `MultiSceneCoordinator` 和 Unity 状态机。

**验收：** 同一时刻只有一个活动业务场景；旧 `transitionId` 的迟到回调不能改变当前场景；加载失败可返回结构化错误并尝试恢复上一个稳定场景。

## 任务-018：内部场景切换协议

**前置：** 任务-017、现有 `power3d-unity` 协议。

**需求：** 新增 `switchScene`、`sceneLoadProgress`、`sceneChanged`，补齐场景标识、事务标识、版本、请求确认和能力声明。

**交付：** 前端协议类型、Unity 浏览器桥、C# 载荷模型和测试。

**验收：** 当前前端可按原请求标识关联结果；未知场景、旧事务和非法进度被拒绝；外层父页面消息不能直接进入该协议。

## 任务-019：桥接管理器跨场景生命周期

**前置：** 任务-016—018。

**需求：** 让 `UnityIframeBridgeManager` 和浏览器监听器跨业务场景常驻，场景切换时重新绑定当前场景控制器，整个子应用释放时才退出 Unity 实例。

**交付：** 跨场景桥接生命周期和幂等释放。

**验收：** 九场景切换不重复注册消息监听器、不产生多个桥接实例；释放后停止全部场景回调，重复释放不抛出异常。

## 任务-020：单发布版本与场景资源拆分

**前置：** 任务-015、017。

**需求：** 建立一个发布目录和构建标识，将基础播放器与九场景重资源分开；优先使用现有 Unity 资产包（AssetBundle），引入可寻址资源系统前先评估版本和缓存方案。

**交付：** 场景资源构建脚本、目录、内容摘要和场景目录文件。

**验收：** 九场景不全部进入首屏单一数据文件；共享资源不被九次重复打包；任一场景资源可独立校验、缓存和回滚。

## 任务-021：流程、聚焦、状态和路径动作适配

**前置：** 任务-016、018。

**需求：** 将 `prepareProcessDetail`、`commitProcessDetail`、`abortProcessDetail`、`exitProcessDetail`、历史兼容 `enterProcessDetail`/`enterProcessStep`、`focusNode`、`clearSelection`、`setNodeVisualState`、`setRouteFlow` 和 `resetScene` 转发给当前场景控制器；统一使用稳定映射标识。准备阶段只加载候选资源且不改变当前展示；提交阶段才切换展示锚点、专用相机位和状态重放；取消准备只释放候选资源。以上命令不操作拓扑。`focusNode` 更新交互描边，并由 `_focusOnSelection` 统一开关决定是否聚焦镜头；`clearSelection` 只取消厂区拓扑选择对应的三维交互描边，不得重置场景、流程、显隐或镜头。Unity 鼠标空白点击另通过 `selectionCleared` 上行事件同步清除厂区二维拓扑选择。

**交付：** Unity 场景命令适配层和命令结果。

**验收：** 命令不再写死燃气默认流程；节点和路径不存在时返回明确错误；状态更新复用材质或材质属性，不为每次更新克隆资源；流程、总览和复位保持当前镜头，节点交互聚焦可由统一开关控制。

## 任务-022：Unity 资源释放与运行诊断

**前置：** 任务-017—021。

**需求：** 释放场景事件、协程、动画、渲染纹理和资源句柄；记录加载时间、首帧、峰值内存、失败阶段和当前场景。

**交付：** 资源治理工具、运行诊断和更新后的 WebGL 构建脚本。

**验收：** 连续切换场景后资源不持续累积；高开销资源回收不在每帧执行；开发构建与生产构建参数分离，正式包不默认开启开发模式。
