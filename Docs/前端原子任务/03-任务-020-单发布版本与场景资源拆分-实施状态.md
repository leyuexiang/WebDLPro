# 任务-020：单发布版本与场景资源拆分实施状态

**状态：** 已完成（100%）
**更新时间：** 2026-08-05

## 已实施

- 保持一个 Unity WebGL 入口。正式构建仅把 Bootstrap 放进主播放器，九个业务场景改由同级 SceneBundles 目录提供，不再全部进入首屏数据文件。
- 新增场景资源构建脚本。它只读取 BusinessSceneCatalog 已登记的九项映射，构建九个独立场景资产包；不扫描模型名称或以文件名猜测业务归属。
- 构建时递归读取 Unity 依赖。被两个及以上场景引用的可打包资产单独进入 scene-shared，由 Unity 清单声明依赖，避免同一公共材质、着色器或图集被重复打包。
- 每个发布目录均生成 SceneBundles/scene-catalog.json 与 SceneBundles/scene-content-summary.json。目录结构版本已升级为 2；前者包含发布标识、场景包、哈希、循环冗余校验、真实文件字节数、依赖图和稳定场景标识，后者列出独占与共享依赖、依赖包闭包、场景内容版本和冷缓存传输体积，供发布核验与回滚追溯。
- 场景内容版本由根场景包及全部共享依赖的“包名 + 内容哈希”按稳定顺序合成；任一共享依赖发生变化都会生成新的场景版本。传输体积按依赖闭包去重求和，不会因菱形依赖重复统计。
- 新增运行时资产包加载器。发布 WebGL 从同级目录下载受限清单，先校验结构版本、发布标识、文件段、非零字节数、哈希、依赖存在性和九场景唯一映射，再以哈希和循环冗余校验加载依赖及场景包并复用 Unity 缓存；编辑器仍按正式目录直接加载，避免人工编辑和编辑器测试依赖已发布包。
- 已修复资源包场景加载编译错误。资源包只负责下载、内容校验和依赖租约，场景一律由 Unity 的 `SceneManager.LoadSceneAsync` 按已核验路径加载；编辑器于 2026-08-04 完成强制同步重编译，未再出现 `AssetBundle.LoadSceneAsync` 的 CS1061 错误，并新增静态防回归断言。
- 加载器在开始下载时即登记临时资源租约。成功、失败、事务取代、场景卸载和运行壳释放均经由同一租约释放内存资产包句柄，不清空版本化磁盘缓存。
- 正式构建使用 Builds/Releases/<发布标识>/unity；已存在的正式发布目录会被拒绝覆盖，构建只在唯一暂存目录完成后整体移动，旧版本可作为明确回滚目标。发布标识可通过命令行 -webglReleaseId 提供，缺省使用项目版本。
- 构建前先生成资产包清单，并传入主播放器构建的资产包清单路径，防止代码裁剪移除仅被业务场景包引用的控制器类型。
- 依赖数据库只对每个场景查询一次；共享依赖统计和内容摘要复用排序后的缓存结果，避免正式构建重复遍历完整资源图。

## 资料边界

- 当前仅燃气发电场景含用户已有的真实业务内容；其余八个场景为明确的空场景占位。构建脚本会建立完整九包结构，但不能把空包误报为八个正式业务资源包。
- 当前未安装可寻址资源系统。本任务已用工程现有的 Unity 资产包模块完成版本、缓存和回滚基础；在没有明确收益与迁移验证前不额外引入。后续若替换为可寻址资源系统，仍必须保持现有目录校验、不可覆盖版本和离线失败边界。
- 正式场景资源所有者、容量基线和单场景内容验收仍由任务-039—047提供；任务-020不改动燃气场景内部资产，也不猜测其余场景模型。

## 验收结论

1. 九场景没有全部进入首屏单一数据文件。正式构建日志只统计 `Bootstrap` 为主播放器第零层，九个业务场景均位于同级独立资产包。
2. 共享资源由构建期真实依赖图判定；两个及以上场景引用的可打包资产只进入一个 `scene-shared` 包。当前只有燃气场景具备真实内容，因此本次产物没有虚构共享包；该事实不影响共享分包算法验收。
3. 任一场景均可通过发布标识、结构版本、内容版本、资产包哈希、循环冗余校验和依赖闭包独立校验；运行时以哈希接入 Unity 版本缓存，正式目录不可覆盖且旧发布目录持续保留，可通过选择旧版本目录完成资源回滚。
4. `task020-final-v2-20260805-231247` 包含 9 个场景、9 个场景包和 9 项内容摘要；全部包字节数与实际文件一致，全部场景内容版本均为 64 位十六进制安全哈希。燃气包和冷缓存传输体积均为 121240836 字节，八个空占位包最小为 26594 字节。
5. 应用内浏览器使用 `gas-power-smoke-task020-v2-5529-20260805-2320` 完成外层宿主页、嵌入壳和 Unity 三层初始化；刷新后再次显示“燃气发电场景与对应拓扑已完成联调初始化”，且内层只有一个网页图形画布。
