# 九场景配置与映射任务

本文件的九项任务彼此独立，可并行领取。每项都必须按照[场景拓扑动作映射规范](场景拓扑动作映射规范.md)提交完整资料，不能只提交一个 Unity 场景文件或一张拓扑图。

每项统一交付：

- Unity 场景键和资源版本。
- 默认拓扑和全部可切换拓扑。
- 外部 `actionId` 清单。
- 动作到场景、拓扑、流程、节点和路径的映射。
- 拓扑 `nodeId → deviceId → sceneNodeId` 映射。
- 场景资源预算、加载策略、失败和降级规则。
- 配置、动作、设备和 Unity 场景映射版本。
- 单元、Unity 编辑器和三层联调证据。

## 任务-039：燃煤发电场景配置与映射

**前置：** 任务-015—038。

**需求：** 完成 `coal-power` 的 Unity 场景、默认拓扑、多拓扑、动作、设备、流程和路径映射。

**交付：** 燃煤发电完整场景包和清单条目。

**验收：** 初始进入、同场景子项、跨场景进入、拓扑单击、设备双击、状态更新、失败恢复和资源释放全部通过；未提供正式关系时不伪造映射。

## 任务-040：燃气发电场景复验与模板冻结

**前置：** 任务-015—038。

**需求：** 将现有燃气三维、控制网络拓扑、流程控制和节点映射迁入新清单，补齐多拓扑、外层通信和双击设备事件；作为后续八场景模板。

**交付：** `gas-power` 完整场景包、清单条目、联调记录和模板说明。

**验收：** 复用现有视觉与通信能力但不保留三栏工作台；同场景流程不重建 Unity；现有燃气节点映射逐项核对，不根据截图补造设备标识。
