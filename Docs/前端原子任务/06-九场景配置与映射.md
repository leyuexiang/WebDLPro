# 九场景配置与映射任务

> **2026-08-15 协议纠偏：** 九场景只交付全局唯一 `nodeId` 和可选 `sceneNodeId`。平台读取 `nodeId` 后在平台内部绑定真实设备编号，不向我方清单注入任何设备字段；任务-056已完成旧绑定模型的本地迁移。

本文件的九项任务彼此独立，可并行领取。每项都必须同时按照[场景模型节点与拓扑节点命名规范](场景模型节点与拓扑节点命名规范.md)和[场景拓扑动作映射规范](场景拓扑动作映射规范.md)提交完整资料，不能只提交一个 Unity 场景文件或一张拓扑图。

每项统一交付：

- Unity 场景键和资源版本。
- 默认拓扑和全部可切换拓扑。
- 外部 `actionId` 清单。
- 动作到场景、拓扑、流程、节点和路径的映射。
- 拓扑 `nodeId → 可选 sceneNodeId` 结构映射和 `doubleClickBehavior`；所有业务源拓扑节点必须为 `emit-node`。非业务说明、分组和层级标题使用元数据表达，不得创建伪业务节点。结构清单不得包含 `deviceId`、设备映射或绑定计数。
- 场景资源预算、加载策略、失败和降级规则。
- 配置、动作、结构映射和 Unity 场景版本；平台内部绑定变化不改变我方结构清单版本。
- 单元、Unity 编辑器和三层联调证据。
