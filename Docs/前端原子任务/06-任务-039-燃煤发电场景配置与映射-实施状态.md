## 未收到且必须提供的正式资料

本任务需要以下资料同时到位后，才可开始写入真实清单或 Unity 内容：

1. Unity 燃煤场景交付物：稳定 `unitySceneKey`、资源版本、场景资源预算、加载策略、失败与降级策略，以及场景中可对外暴露的 `sceneNodeId` 清单。
2. 默认拓扑与全部可切换拓扑：每个拓扑的正式 `topologyId`、节点、连线、二维布局、图元键和状态基线。
3. 设备主数据映射：每个可双击或接收状态的节点提供 `nodeId → deviceId → sceneNodeId` 显式关系；概念节点必须明确标记为不可双击。
4. 动作与流程映射：外部 `actionId`、目标拓扑、流程 `processId + stepId`、节点聚焦、路径和失败策略；不接受菜单文案或模型名字代替标识。
5. 验收与版本资料：场景、拓扑、动作、设备和 Unity 映射版本必须可作为同一发布版本原子交付，并提供单元、Unity 编辑器及三层联调的可复现验收条件。

## 当前保护性结论

1. 不会把 `CoalPower.unity` 的文件名、场景路径、占位根对象或六个燃煤页面名称解释为任何燃煤设备、模型、流程步骤或拓扑节点。
2. 在正式映射到位前，燃煤请求继续返回 `scene-content-unavailable`，由多场景协调器恢复至当前稳定场景；这是一项安全边界，不是燃煤业务功能验收。
3. 不会复制燃气的 24 节点拓扑、六条聚焦映射或七项流程步骤到燃煤场景。燃气模板只复用清单结构、验证规则和“不猜测”原则。
