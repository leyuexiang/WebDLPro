## 🎯 核心功能展示

### 时间锁定流程

```
应用启动
    ↓
初始化安全管理器
    ↓
检查当前时间
    ↓
┌─────────────────┐
│ 是否已过期？     │
└─────────────────┘
    ↓ 是           ↓ 否
拒绝运行       检查时间回拨
显示提示           ↓
    │          是否回拨？
    │              ↓ 是
    │          拒绝运行
    │              ↓ 否
    │          检查警告期
    │              ↓
    └──────> 正常运行
```

### 消息加密流程（可选）

```
前端发送
    ↓
序列化 payload
    ↓
AES-256 加密
    ↓
Base64 编码
    ↓
添加 "ENC:" 标记
    ↓
发送到 Unity
    ↓
Unity 检测标记
    ↓
Base64 解码
    ↓
AES-256 解密
    ↓
反序列化
    ↓
正常处理
```

## 🚀 快速使用

### 1. 配置过期日期（30秒）

```bash
cd power-data-web/src/host-bridge

# 设置90天试用期
node configure-security.js --days 90

# 或设置到具体日期
node configure-security.js --date 2027-12-31
```

### 2. Unity 集成（已完成）

安全检查已自动集成到 `UnityIframeBridgeManager.cs`，无需额外操作。

### 3. 前端集成（5分钟）

在 `App.vue` 中添加：

```vue
<script setup lang="ts">
import { onMounted } from 'vue';
import { useSecurityInit } from '@/host-bridge/security-example';

const { isExpired, showWarning, initializeSecurity } = useSecurityInit();

onMounted(async () => {
  await initializeSecurity();
});
</script>

<template>
  <div v-if="isExpired" class="expired-overlay">
    <h1>系统已过期</h1>
    <p>请联系开发商续期</p>
  </div>
  <div v-else>
    <!-- 正常内容 -->
  </div>
</template>
```

### 4. 测试验证

```bash
# Unity: 添加 SecurityTestRunner 组件并运行
# 前端: 
cd power-data-web
npm run test

# 演示:
node src/host-bridge/demo-security-simple.js
```

## 🛡️ 保护能力

### ✅ 能够防止

- **普通用户随意使用** - 时间到期后自动失效
- **简单时间调整** - 防时间回拨机制

- **代码篡改** - 修改编译后代码

### 🎯 实际定位

这是一套**实用的基础保护方案**，主要作用是：

1. **防止无意拖欠** - 善意客户不会故意破解
2. **商务谈判筹码** - 有技术限制作为保障
3. **法律证据** - 明确的试用期和技术措施
4. **心理威慑** - 增加破解门槛和风险

**核心原则**：技术保护是辅助，主要依靠商业合同和信任关系。
