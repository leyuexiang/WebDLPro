# 首屏区域高亮与轮询：外层对接说明

> 适用范围：`Overview.unity` 首屏沙盘六按钮（调度中心/发电/输变电/配电/用电/微电网）与轮询按钮的三维功能。
>
> **状态（2026-10-06 更新）：对接已完成。** 外层 UI 按钮可经 `workflow.trigger` 动作通道全链路触发，链路分层与切场景完全一致。

## 1. 结论：与切场景方式是否相同

**相同（已对接）。** 区域高亮与轮询完全按切场景的分层方式接入：

父页面 → host-bridge（`workflow.trigger`，按 `actionId`）→ `WorkflowTriggerTransactionHandler`（区域动作不切视图，直接投影 Unity 区域命令）→ jslib 白名单校验 → `UnityIframeBridgeManager` → `OverviewAreaHighlightController` → `commandResult` 回执。

与切场景的唯一差别：区域动作不切换视图、不产生新稳定上下文版本（`keep-current-context`），回执 `contextRevision` 保持当前值。

## 2. Unity 侧 API（接线终点）

组件：`Overview.unity → OverviewRuntime → OverviewAreaHighlightController`（`WebDLPro.Unity.SceneRuntime`）。

| API | 说明 |
| --- | --- |
| `ActivateArea(string areaId)` | 激活区域。`areaId` 闭集：`dispatch-center` / `generation` / `transmission` / `distribution` / `consumption` / `microgrid` |
| `Deactivate()` | 恢复默认共享材质、隐藏光晕、停止飞线 |
| `SetPolling(bool)` | 轮询开关。开启立即从调度中心起播，按按钮栏顺序每 3 秒自动切换循环；关闭恢复默认 |
| `IsPollingActive` / `PollingCurrentAreaId` / `PollingSecondsUntilNextSwitch` | 状态读取 |
| `CollectConfigurationProblems()` | 静态配置校验 |

返回 `BusinessSceneCommandResult { Success, ErrorCode, Message }`，映射为标准 `commandResult` 回执。

行为语义（外层可依赖的稳定契约）：
- 调度中心 = 飞线动画（播完自动隐藏，重复点击重播）+ 调度中心围栏高亮，两者同时生效；
- 五个围栏组 = 统一主题色 #5DDDD8、围栏亮度 1↔3.5 波动、底面改色、光晕显示；
- 区域间互斥：激活新区域前先回滚上一个区域（全部围栏共享同一材质资产，运行时按渲染器实例化，不影响资产）；
- 重复点击同一区域幂等保持；未知 `areaId` 返回失败；
- 轮询运行中手动激活任意区域或恢复默认 = 接管，轮询自动终止。

## 3. 公开动作清单（workflow.trigger 入口）

| actionId | Unity 动作 | 说明 |
| --- | --- | --- |
| `action.overview.area.dispatch-center` | `activateOverviewArea { areaId: 'dispatch-center' }` | 调度中心（飞线+围栏） |
| `action.overview.area.generation` | `activateOverviewArea { areaId: 'generation' }` | 发电 |
| `action.overview.area.transmission` | `activateOverviewArea { areaId: 'transmission' }` | 输变电 |
| `action.overview.area.distribution` | `activateOverviewArea { areaId: 'distribution' }` | 配电 |
| `action.overview.area.consumption` | `activateOverviewArea { areaId: 'consumption' }` | 用电 |
| `action.overview.area.microgrid` | `activateOverviewArea { areaId: 'microgrid' }` | 微电网 |
| `action.overview.polling.start` | `setOverviewPolling { enabled: true }` | 开始轮询 |
| `action.overview.polling.stop` | `setOverviewPolling { enabled: false }` | 停止轮询 |

全部动作 `targetSceneId: 'overview'`、`targetViewMode: 'overview'`、空参数白名单、`failurePolicy: 'keep-current-context'`。轮询按钮由父页面按当前状态选择 start/stop 两个无参动作。
