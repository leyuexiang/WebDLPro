# 设备展示场景使用说明

## 场景入口

测试场景：`Assets/Scenes/DeviceShowcaseTest.unity`

当前场景用于展示 `整体` 模型，支持展示完整模型，也支持展示 `整体` 下的一级设备。

## 展示对象规则

展示控制器位于：`DeviceShowcaseRuntime`

脚本：`Assets/Scripts/PowerPlant/DeviceShowcaseController.cs`

可展示对象包括：

- `整体`
- `整体` 下的一级子对象，例如：
  - `燃气轮机`
  - `余热锅炉`
  - `发电机`
  - `低中高压汽轮机`
  - `凝汽器`
  - `变压站+电网`

默认展示对象：`整体`

如果要修改默认展示对象，在 `DeviceShowcaseRuntime` 的 `DeviceShowcaseController` 上修改 `Default Device Id`。

## Unity 内测试方式

进入 Play Mode 后：

- 默认展示 `整体`
- 按 `F5`：切换到上一个展示对象
- 按 `F7`：切换到下一个展示对象
- 按 `F6`：退出设备展台

开发/编辑器测试面板也提供“设备展台”区域，可以输入设备名并点击“展示设备”。

## 镜头控制

镜头控制脚本挂载在：`Main Camera`

脚本：`Assets/Scripts/PowerPlant/DeviceShowcaseCameraController.cs`

操作方式：

- 按住鼠标右键并拖动：旋转镜头
- 鼠标滚轮：放大 / 缩小
- 左键平移当前已关闭

可调参数：

- `Rotation Sensitivity`：右键旋转灵敏度
- `Enable Pan`：是否启用左键平移
- `Zoom Sensitivity`：滚轮缩放灵敏度
- `Min Distance`：最近缩放距离
- `Max Distance`：最远缩放距离

## 前端 iframe 指令

Unity 通过 `UnityIframeBridgeManager` 接收前端消息。

### 展示指定对象

```json
{
  "channel": "power3d-unity",
  "version": 1,
  "instanceId": "local-demo-001",
  "messageId": "show-whole-001",
  "type": "showDevice",
  "payload": {
    "deviceId": "整体"
  },
  "timestamp": 0
}
```

展示具体设备：

```json
{
  "channel": "power3d-unity",
  "version": 1,
  "instanceId": "local-demo-001",
  "messageId": "show-gas-turbine-001",
  "type": "showDevice",
  "payload": {
    "deviceId": "燃气轮机"
  },
  "timestamp": 0
}
```

`payload.deviceId` 也可以换成 `payload.deviceCode`，当前二者都会按展示对象名称查找。

### 退出设备展台

```json
{
  "channel": "power3d-unity",
  "version": 1,
  "instanceId": "local-demo-001",
  "messageId": "exit-showcase-001",
  "type": "exitDeviceShowcase",
  "payload": {},
  "timestamp": 0
}
```

## 返回状态

执行命令后，Unity 会通过 `commandResult` 返回结果。

`payload.sceneState` 中会包含当前展台状态：

- `showcase=整体`
- `showcase=燃气轮机`
- `showcase=off`

## 注意事项

- 展示对象名称必须与 Unity 层级中的对象名一致。
- 当前只支持 `整体` 或 `整体` 下的一级子对象直接展示。
- 展示时会复制一份展示对象到运行时展台，不会修改原始模型本体。
- 展台中的灰色线框地盘和循环箭头是运行时生成的视觉对象，不会作为持久子对象保存到场景中。
