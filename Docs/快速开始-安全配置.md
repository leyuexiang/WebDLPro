# 通信加密与时间限制 - 快速开始

## 📋 概述

本指南帮助你快速启用项目的安全保护功能。

---

## ⚡ 快速配置（5分钟）

### 1. 设置过期日期

使用配置工具快速设置：

```bash
# 进入前端目录
cd power-data-web/src/host-bridge

# 查看当前配置
node configure-security.js --show

# 设置90天试用期（从今天开始）
node configure-security.js --days 90

# 或者设置到具体日期过期
node configure-security.js --date 2024-12-31
```

### 2. 手动配置（如果需要）

编辑 `power-data-web/src/host-bridge/security-config.ts`：

```typescript
export const SECURITY_CONFIG = {
  BASE_DATE: '2024-01-01',    // 起始日期
  TRIAL_DAYS: 180,             // 试用天数
  // ... 其他配置
};
```

同步修改 Unity 端 `Assets/Scripts/Security/CommunicationSecurityManager.cs`：

```csharp
private DateTime CalculateExpirationDate()
{
    DateTime baseDate = new DateTime(2024, 1, 1);  // 与前端一致
    int obfuscatedDays = 180;                       // 与前端一致
    return baseDate.AddDays(obfuscatedDays);
}
```

### 3. 集成到应用入口

编辑你的 `App.vue` 或主入口文件：

```vue
<template>
  <!-- 过期遮罩层 -->
  <div v-if="isExpired" class="expired-overlay">
    <div class="expired-message">
      <h1>系统已过期</h1>
      <p>{{ warningMessage }}</p>
      <div class="contact-info">
        <p>联系方式：{{ vendorContact.email }}</p>
      </div>
    </div>
  </div>

  <!-- 过期警告横幅 -->
  <div v-else-if="showWarning" class="warning-banner">
    <span>⚠️ {{ warningMessage }}</span>
    <button @click="showWarning = false">知道了</button>
  </div>

  <!-- 正常内容 -->
  <router-view v-if="!isExpired" />
</template>

<script setup lang="ts">
import { onMounted } from 'vue';
import { useSecurityInit } from '@/host-bridge/security-example';

const {
  isExpired,
  showWarning,
  warningMessage,
  vendorContact,
  initializeSecurity,
} = useSecurityInit();

onMounted(async () => {
  await initializeSecurity();
});
</script>

<style scoped>
.expired-overlay {
  position: fixed;
  inset: 0;
  background: rgba(0, 0, 0, 0.95);
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: 9999;
}

.expired-message {
  background: white;

  border-radius: 12px;
  text-align: center;
  max-width: 500px;
}

.warning-banner {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;

  color: white;
  padding: 12px 20px;
  display: flex;
  align-items: center;
  justify-content: space-between;
  z-index: 1000;
}
</style>
```

### 4. 重新编译

```bash
# 前端
cd power-data-web
npm run build

# Unity
# 打开 Unity 编辑器，等待脚本重新编译
# 然后构建 WebGL 项目
```

## 🎯 常见场景

### 场景1：演示版（30天试用）

```bash
node configure-security.js --days 30
```

客户验收期间使用，到期后自动失效。

### 场景2：开发版（6个月）

```bash
node configure-security.js --days 180
```

给客户开发期间使用的版本。

### 场景3：指定截止日期

```bash
node configure-security.js --date 2024-06-30
```

明确到某个日期过期。

### 场景4：正式版（无限期）

注释掉 Unity 和前端的过期检查代码，或者设置一个很远的日期（如2099年）。

## 🔒 启用消息加密（可选）

编辑 `security-config.ts`：

```typescript
export const ENCRYPTION_CONFIG = {
  ENABLE_ENCRYPTION: true,  // 启用加密
  ENCRYPTED_COMMANDS: ['*'], // 加密所有命令
};
```

或选择性加密：

```typescript
export const ENCRYPTION_CONFIG = {
  ENABLE_ENCRYPTION: true,
  ENCRYPTED_COMMANDS: [
    'switchScene',
    'enterProcessStep',
    'setNodeVisualState',
  ],
};
```

## ✅ 验证配置

### 前端验证

打开浏览器控制台，应该看到：

```
[Security] 系统过期日期: 2024-06-30
```

如果临近过期（7天内），会看到：

```
[Security] 系统将在 5 天后过期，请及时续期。
```

如果已过期：

```
[Security] 系统试用期已过期，请联系开发商续期。
```

### Unity 验证

打开 Unity 编辑器，查看 Console：

```
[UnityIframeBridge] 系统过期日期: 2024-06-30
```

或过期时：

```
[UnityIframeBridge] 系统试用期已过期，无法启动。
```

## 🛠️ 故障排除

### 问题1：Unity 和前端过期日期不一致

**原因**：两端配置不同步

**解决**：使用 `configure-security.js` 工具自动同步，或手动确保两端配置一致。

### 问题2：过期后仍然可以使用

**原因**：可能未重新编译，或检查代码被注释

**解决**：
1. 确认代码中的检查逻辑存在
2. 重新编译 Unity 和前端
3. 清除浏览器缓存

### 问题3：加密消息解析失败

**原因**：Unity 和前端密钥不一致

**解决**：确保两端的密钥生成逻辑完全一致，或暂时关闭加密。
