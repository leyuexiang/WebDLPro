## 🎯 Unity 端测试

### 方法1：使用测试运行器（推荐）

1. **打开 Unity 编辑器**

2. **创建测试对象**
   - 在 Hierarchy 中创建空 GameObject
   - 命名为 "SecurityTestRunner"
   - 添加 `SecurityTestRunner` 组件

3. **运行测试**
   
   在 Inspector 中：
   - 勾选 "Run Tests On Start"
   - 点击 Play 按钮
   - 查看 Console 输出

   或使用右键菜单：
   - 右键点击组件
   - 选择 "运行所有测试"

4. **查看结果**

   ```
   ====================================
   开始安全管理器测试
   ====================================

   [测试1] 时间验证测试
   ✓ 系统正常运行，剩余 165 天

   [测试2] 加密功能测试
   原始文本：Hello Unity Security Test 123!
   加密结果：Zx9Kj3mP8... 
   ✓ 加密成功

   [测试3] 解密功能测试
   原始文本：Test Decryption 解密测试 456
   解密文本：Test Decryption 解密测试 456
   ✓ 解密成功，内容一致

   [测试4] 往返加密解密测试
   ✓ 通过：简单文本
   ✓ 通过：English Text
   ✓ 通过：混合 Mixed 内容 123
   ✓ 通过：{"type":"test","value":123}
   ✓ 通过：特殊字符!@#$%^&*()
   
   测试结果：通过 5/5，失败 0/5

   [测试5] 过期行为测试
   系统未过期，跳过过期行为测试

   ====================================
   测试完成
   ====================================
   ```

5. **单独测试**

   可以在 Inspector 右键菜单选择单个测试：
   - 测试 - 时间验证
   - 测试 - 加密功能
   - 测试 - 解密功能
   - 测试 - 往返加密解密
   - 测试 - 过期行为
   - 测试 - 性能测试
   - 显示配置信息

### 方法2：使用脚本 API

在任何 MonoBehaviour 中调用：

```csharp
using WebDLPro.Unity.Security;

// 检查是否过期
bool isExpired = CommunicationSecurityManager.Instance.IsExpired();
Debug.Log($"系统状态: {(isExpired ? "已过期" : "正常")}");

// 获取剩余天数
int days = CommunicationSecurityManager.Instance.GetRemainingDays();
Debug.Log($"剩余天数: {days}");

// 加密
string encrypted = CommunicationSecurityManager.Instance.EncryptPayload("测试");

// 解密
string decrypted = CommunicationSecurityManager.Instance.DecryptPayload(encrypted);
```

### 方法3：集成到应用中测试

在 `App.vue` 或任何组件中：

```typescript
import { securityManager } from '@/host-bridge/communication-security';

// 初始化
await securityManager.initialize();

// 检查状态
console.log('是否过期:', securityManager.checkExpired());
console.log('剩余天数:', securityManager.getRemainingDays());

// 测试加密
const encrypted = await securityManager.encryptPayload('测试');
console.log('加密结果:', encrypted);

// 测试解密
const decrypted = await securityManager.decryptPayload(encrypted);
console.log('解密结果:', decrypted);
```

## 🔄 集成测试

### 测试1：Unity 和前端密钥一致性

**目标**：验证 Unity 加密的内容能被前端解密，反之亦然

**步骤**：

1. **Unity 端加密**
   ```csharp
   string plainText = "Integration Test 集成测试";
   string encrypted = CommunicationSecurityManager.Instance.EncryptPayload(plainText);
   Debug.Log($"Unity 加密: {encrypted}");
   ```

2. **复制加密结果到前端**
   ```typescript
   const encrypted = "从Unity复制的加密字符串";
   const decrypted = await securityManager.decryptPayload(encrypted);
   console.log('前端解密:', decrypted);
   ```

3. **验证**：前端解密结果应该等于原始文本

4. **反向测试**：前端加密 → Unity 解密

**预期结果**：✓ 双向解密成功

### 测试2：过期后通信阻断

**步骤**：

1. **修改系统时间**到过期日期之后
   - Windows: 右键任务栏时间 → 调整日期/时间
   - 设置到配置的过期日期之后

2. **启动 Unity**
   - 查看 Console 应该显示：
   ```
   [UnityIframeBridge] 系统试用期已过期，无法启动。
   ```

3. **启动前端应用**
   - 应该显示过期遮罩层
   - 无法进入主界面

4. **尝试通信**
   - Unity 应该拒绝所有消息
   - 前端应该无法发送消息

**预期结果**：✓ 过期后完全阻断通信

### 测试3：过期警告显示

**步骤**：

1. **设置过期日期为7天后**
   ```bash
   node configure-security.js --days 7
   ```

2. **重新编译 Unity 和前端**

3. **启动应用**
   - Unity Console 应该显示警告
   - 前端应该显示警告横幅

**预期结果**：✓ 正确显示过期警告

## 🐛 故障排除

### 问题1：Unity 测试失败 - 找不到类型

**错误信息**：
```
The type or namespace name 'Security' does not exist
```

**解决方法**：
1. 确认文件在正确位置：`Assets/Scripts/Security/`
2. 等待 Unity 自动编译完成
3. 如果仍然失败，手动刷新：Assets → Refresh

### 问题2：前端测试失败 - 加密解密不一致

**错误信息**：
```
Expected decrypted to equal plainText
```

**可能原因**：
- Unity 和前端密钥不一致
- 配置文件未同步

**解决方法**：
1. 使用配置工具重新同步
   ```bash
   node configure-security.js --days 180
   ```
2. 确认两端配置一致
3. 重新编译

### 问题3：过期行为测试跳过

**信息**：
```
系统未过期，跳过过期行为测试
```

**这是正常的**！要测试过期行为：
1. 修改系统时间到过期日期之后
2. 重新运行测试
3. 测试完成后恢复系统时间

### 问题4：性能测试很慢

**原因**：加密解密是CPU密集型操作

**正常性能**：
- 加密：< 1 ms/次
- 解密：< 1 ms/次

**如果超过**：
- 考虑只加密敏感命令
- 减少高频消息加密
- 使用更快的硬件
